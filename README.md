# 量化选基系统 V3.1

基于《量化选基系统核心打分模型_V3》的可执行实现，附 Web 控制台。

## 快速开始

```bash
pip install akshare pandas numpy scikit-learn flask
cd quant_fund_picker
python webapp.py
```

浏览器打开 **http://127.0.0.1:8000**

| 功能 | 操作 |
|---|---|
| 估值地形图 | 打开页面自动加载（12因子面板 5年PE分位） |
| 全市场扫描 | 点【开始全市场扫描】按钮 → 后台爬取+RBSA+风控，进度实时显示 |
| 单基金透视 | 输入基金代码点【爬取并解剖】→ 实时爬取该基金全部数据并打分（AUM/经理任期/RBSA/风控瀑布图） |
| 支付宝持仓批算 | 粘贴持仓代码（每行一个）→ 批量出分 |
| 点榜单任意行 | 直连该基金的深度解剖页 |

缓存机制：当日已爬数据存于 `cache/`，同一天重跑秒级完成；跨交易日自动刷新。
命令线模式：`python run_demo.py [代码...]` / `python scan_market.py 400 150`。

## 模型公式

```
S_total = (0.40×min(F_value,100) + 0.35×F_alpha + 0.25×F_momentum) × Π(1−惩罚率)
评级: 85+ StrongBuy | 70+ Buy | 50+ Hold | <50 Sell/Avoid
```

## 结构

```
config.py     模型参数/12因子面板定义
provider.py   数据层（天天基金/乐咕/中证/雪球，本地缓存）
rbsa.py       Ridge-RBSA 底层穿透（60日窗口×3错位取均，L2非负约束）
factors.py    F_value/F_alpha/F_momentum 三大因子
risk.py       风控乘数与一票否决
engine.py     单基流水线 + 截面排名 + 总分合成
scan_market.py 全市场三层漏斗扫描器（CLI）
report.py     投研报告生成器
webapp.py     Web 控制台（Flask）
templates/index.html 前端页面
output/       scores/scan 结果 （csv/json）
```

## 使用详解

### 页面六大区块（从上到下的推荐看法）
1. **大盘水位计 + regime**：先看它定总仓位。≥90% 收手 / 20-90% 按榜操作 / ≤20% 左侧模式
2. **估值地形**：12个风格+行业指数的五年PE分位，找洼地
3. **全市场扫描**：点按钮 → 后台爬取+深算（首次约4-6分钟, 当日缓存后约40秒）
4. **评分榜单**：可按总分/估值/动量排序、按评级/通道筛选、搜索；点击任意行进瀑布
5. **单基金透视**：任意代码 → 实时爬取+完整瀑布（新发基金会提示历史不足）
6. **持仓批算**：粘贴你的支付宝持仓代码（每行一个）→ 批量出分

### 榜单覆盖范围（不是全部基金！）
全市场 27,417 只 → 类型过滤(偏股/普通股票/指数股票/灵活配置, 剔除C/E重复份额) 4,530 只
→ 要求近3年业绩存在(≥3年牛熊窗口) → **双通道抽 550 只深算**：
- **右侧池**：近3年收益前 N 名（默认400）——强势/绩优候选，捕捉真Alpha与顺风趋势
- **左侧池**：近1年跌幅最深前 M 名（默认150）——落难/低估候选，捕捉"处于低点、未来可能涨"的品种
左右用同一把尺子评分：左侧基金必须过"趋势确认+风控"才能脱颖而出（防价值陷阱），
右侧基金必须过"估值关"（防追高）。两池大小可在网页上自行调大。

### 评分读法
```
85+ StrongBuy(重仓/加定投) | 70-84 Buy(分批建仓) | 50-69 Hold(观望) | <50 规避
一票否决项: 经理<3年 | 超额回撤比值>1.5 → 总分直接归零
```

⚠️ 仅供量化研究，不构成投资建议。
