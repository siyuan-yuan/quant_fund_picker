## 快速开始

```bash
pip install akshare pandas numpy scikit-learn flask

```

浏览器打开 **http://127.0.0.1:8000**。服务默认只监听本机，避免局域网用户读取你的持仓台账；


### Windows 闪退：`Check failed: !IsConfigurablePoolInitialized()`

这不是 Flask 业务报错，是 **akshare → py_mini_racer 内嵌的 V8** 进程级致命断言。
新版 Chromium PartitionAlloc 每个进程只能 Init 一次；waitress 多线程、超时弃线程、
或 akshare 每次调用都 `MiniRacer()`，第二次就会把 `python.exe` 直接打死（栈顶是 `mini_racer.dll`）。

本仓库已处理：启动时把 MiniRacer 钉成永不销毁的单例（`v8_guard.py`），净值/名录改走东财 HTTP。
若仍崩溃，降级到旧 V8：

```bash
pip uninstall mini-racer py-mini-racer -y
pip install py-mini-racer==0.6.0
python webapp.py
```

不要用 Flask `debug=True` / reloader（会 fork 出第二个 V8）。

| 功能 | 操作 |
|---|---|
| 估值地形图 | 打开页面自动加载（12因子面板 5年PE分位） |
| 全市场扫描 | 点【开始全市场扫描】按钮 → 后台爬取+RBSA+风控，进度实时显示 |
| 单基金透视 | 输入基金代码点【爬取并解剖】→ 实时爬取该基金全部数据并打分（AUM/经理任期/RBSA/风控瀑布图） |

缓存机制：当日已爬数据存于 `cache/`，同一天重跑秒级完成；跨交易日自动刷新。

仓库只保留一份最新扫描快照和模型裁决报告作为启动基线。回测、扫描和研究输出请保存在本地或外部制品存储。
命令线模式：`python scan_market.py 400 150`。

## 模型公式

**V3.7 规则合成模型（唯一模型，2026-08-10 起）**

```
S_total = (0.40×min(F_value,100) + 0.35×F_alpha + 0.25×F_momentum) × Π(1−惩罚率)
```

* **F_value** —— 估值分位（5 年 PE 分位）+ 趋势确认滤网（MACD/MA20 右侧反转）+ 缩量加分信号
* **F_alpha** —— 动态基准（RBSA 十六因子穿透）滚动 IR 胜率 + 下行捕获率
* **F_momentum** —— 滞后截面动量（4M-1M / 7M-1M 相对排名）
* **风控惩罚** —— 回撤比值平滑惩罚 / 任期归因平滑折价 / 规模反噬 / 集中度

**★ 2026-08-10 模型动物园裁决（`output/model_zoo_report.md`）★**

全历史严格 walk-forward（2006-09→2026-03，235 个月末 × 217 只，无前视协议）对 66 个
机器学习配置（Huber/Lasso/ElasticNet/树模型/MLP/集成 × 3 特征集 × 4 目标）与 V3.7 做对决：

| 指标 | **V3.7（最优）** | 最高 ML 配置（Lasso） | 原 V4×0.5 混合 |
|---|---:|---:|---:|
| 全历史 OOS IC | **0.113** (t=8.1) | 0.096 | 0.088 |
| 端到端回测 Calmar（full/2015+/2019+） | **0.33 / 0.27 / 0.64** | 0.32 / 0.30 / 0.49 | 0.27 / 0.19 / 0.39 |

结论：**V3.7 即为最优模型**（IC 与回测双冠、三年代稳定、胜率 59% 换手最低）。
此前"V4 最优"的结论来自小池子（2019-03→2025-12）+ 含前视标签协议的双重高估；
V4 实验代码、模型文件与产物已全部移除，评分引擎只保留 V3.7。
若未来考虑引入机器学习分散腿，证据指向 ElasticNet/Lasso（V4 同款 7 特征、fwd6 rank 目标）×0.3 权重（见报告 4.1/5.1）。

### 持仓诊断：入场高点回撤止损 + CPPI 动态槽位（自动计算真实数据）

**持仓台账（推荐，支持分批买入/卖出）：** 在「持仓诊断」面板填写
**基金代码 + 方向(买入/卖出) + 日期(每行一条, 支持多条) + 金额(与日期一一对应)**，
一次可批量录入同一基金的多笔操作；日期与金额数量不一致会提示。保存在
`output/ledger.json`（本地、自动保存）：

```
基金代码 161725  方向 买入  日期 2021-06-01 / 2023-02-01  金额 20000 / 10000
基金代码 161725  方向 卖出  日期 2025-09-01              金额 8000
```

- 同一基金**任意多笔买入/卖出**；卖出按**先进先出（FIFO）**扣减份额与成本；
- **导出台账 / 导入台账**：CSV（UTF-8）或 JSON 备份与恢复；CSV 格式
  `日期,方向,代码,金额[,备注]`（方向支持 买入/卖出/buy/sell），导入自动按
  代码+日期+方向+金额去重合并；
  全部卖完自动从诊断中剔除（不参与回撤与 CPPI）；
- 之后只需补记新操作，持仓诊断自动读取台账，**无需每次重输持仓**；
  诊断结果里每个「清仓/卖出」行有 **卖出→台账** 按钮、每条买入建议有 **买入→台账**
  按钮（金额可改），执行操作后一键记入；
- 「把台账基金填入上方持仓框 → 生成方案」可把台账基金按系统计算的市值
  （第 3 列为自动算出的持有收益率）填入输入框核对后生成方案；
- 「从持仓诊断导入」可把持仓诊断输入框里的持仓行一键转成台账买入记录
  （仅导入含买入日期/成本的；按净值折算成本，自动去重）。

**一次性输入（无台账时）：** 每行 `代码 市值 [买入日期 | 成本 | 收益率%]`

```
110011 2.5万 2023-03-15    # 市值 + 买入日期（交易记录里看，最准）
161725 1.8万 1.6万         # 市值 + 成本金额
003096 1.2万 +8.5%         # 市值 + 持有收益率 → 自动反推入场日
```

**台账金额口径（V3.10）：**
- **买入金额 = 你填的扣款总金额（含申购费）**，系统自动扣费后折份额：
  净申购金额 = 总金额 / (1 + 申购费率)，确认份额 = 净申购 ÷ 当日净值。
  例：填 `190`、费率 0.12% → 净申购 `190/1.0012 = 189.77`，份额 = 189.77 ÷ 当日净值。
- **费率自动查**（`provider.get_fund_buy_fee`）：从天天基金 `fund_fee_em` 自动读取该基金
  **折后实扣申购费率**（优先天天基金优惠费率，无优惠回退原费率），A类/C类各查各的，
  缓存到 `cache/fee_<code>.json`。台账顶部可直接设置“默认费率”和任意“单基金费率”，
  优先级为：**用户单基金覆盖 > 自动查费 > 用户默认费率**。设置持久化在
  `output/fee_settings.json`；首次使用以 `config.BUY_FEE_RATE / BUY_FEE_BY_FUND` 初始化。
  因渠道优惠不同可自行覆盖，例如 016452 填 `0.12%`，C 类免申购费可填 `0%`。
- **买入日期 = 下单日**（北京时间 15:00 前=当天、15:00 后=下一交易日）；系统用下单日的
  净值确认份额，无需你填确认日。**QDII / 海外基金**：确认净值尚未披露的下单记「在途」，
  按扣款金额计入持有金额、不按最新净值折份额（016452 这类 T+2 确认、净值滞后 1～2 天
  的品种，否则会把「昨天未确认的 10 元」错记成已确认份额）。A 股基金仍按 T 日净值确认。
- **卖出金额 = 净到账**（赎回费默认 0，见 `config.SELL_FEE_RATE`）。

**自动计算（天天基金真实复权净值，无需自己维护任何曲线）：**

1. **单基金两条回撤 + 20% 持仓回撤止损**（`STRAT_TRAIL_STOP=0.20`）：
   - **持仓回撤** `dd`：本轮开仓以来最高净值 → 当前；台账多笔买卖采用现金流中性口径，加仓不刷新高点、减仓不制造回撤。止损只看这一列。
   - **基金高点回撤** `dd_fund`：整只基金有数据以来最高净值 → 当前；只展示，不触发止损。
   - 持仓回撤 ≤ -20% → 自动标记「纪律卖出·入场高点回撤20%」清仓（表中红标 + 订单）；
   - 持仓回撤 ≤ -15% → 「接近止损」警示；未提供入场信息 → 跳过判断并提示，绝不误报。
2. **组合级 CPPI 三档回撤线**（`config.STRAT_CPPI_*`）：用 市值×复权净值比 重建组合净值曲线
   （与 成本×净值比 严格等价，因此市值+日期即可），计算 HWM 与当前回撤：
   - 回撤 ≤ -15% → **6 槽**；≤ -20% → **3 槽**；≤ -25% → **清仓 0 槽**；
   - 生效槽位 = min(宏观槽位(危机=0), CPPI 档位)，直接改写调仓方案的每槽金额、超槽卖出与可买槽数。
3. **回补提示（减槽后何时加回）**：带 2pp 滞回带（`STRAT_CPPI_HYSTERESIS`）——
   - 回升至 -13% 线恢复满 10 槽；-18% 线恢复 6 槽；-23% 线恢复 3 槽；创出新高直接满槽；
   - 页面给出**具体金额**（如「回升至 ¥86,370 → 恢复 3 槽」）与历史参照（上次站上该线日期），
     并列出真实触发/回补事件时间线（如「2023-10-19 触发-15%线 → 6槽」）。

页面同时绘制组合净值曲线图（含 HWM 与三条 CPPI 线）。台账路径下曲线由每笔买卖
（FIFO 份额×真实复权净值）逐日重建，支持分批买入/卖出与定投；无台账的输入行按
最近一笔近似。现金按常数并入曲线。`python test_holding_diag.py` 为回归测试。

**定投导入（台账面板「定投导入」按钮）：** 填 `代码 + 开始日期 + 每期金额 + 频率(每日/每月/每两周/每周)` →
系统生成扣款日序列（每月同日，31号自动取月末；每日=连续自然日），预览期数/累计投入/
按净值折算的当前市值 → 一键保存为台账买入记录。**自动合并**：保存时自动检测台账中
该基金的主动买入/卖出记录并一并计入（无需手动处理），定投记录带「定投导入」标记。
**★ 自动跳过休市（V3.10）**：在已披露净值的历史区间，扣款日序列只保留该基金实际
有净值的交易日，自动排除 A 股/海外的周末及法定休市；最新净值日之后的工作日作为
“净值待确认”先记入台账，避免 QDII 披露滞后导致当天真实扣款被漏记。

**待补齐定投提醒：** 检测到某基金连续多笔同额定投且下一扣款日已到期时，页面会询问
「定投是否已终止？」。选择「补齐至此日」并填写终止日期（= 明确告知定投已终止）后，
系统将该轮定投**标记为已终止并持久化**（`output/dca_state.json`），之后同一轮不再
反复询问；「直接忽略」同样按轮次持久化。若之后重新开始新一轮定投（出现更晚的扣款记录），
会自动恢复提醒，两轮互不冲突。选择「未终止，补齐至今天」则不设终止标记，按新扣款日继续提醒。
“今日”与下一扣款日一律按浏览器本地日历日（`YYYY-MM-DD`）比较，避免把 ISO 日期当成 UTC
后在到期当天漏提醒（例如周五最后一笔、周一到期的每日定投）。对于净值披露滞后的 QDII，
最新净值日之后的工作日会先记为 **净值待确认**，不会再因 T+1/T+2 披露时滞而漏掉当天扣款，
后续净值更新后自动按真实净值核算。

**定投止盈（分批止盈线）：** 台账面板「定投止盈」模块，选择一只定投基金 → 系统按
「当前复权净值 ÷ 每笔买入复权净值 - 1」逐批次计算涨幅，达到止盈线（默认 20%，可调）的批次
直接给出**建议卖出金额**：推荐「卖利润·留成本」（卖出 = 涨幅×成本，剩余 = 成本继续在场，
本金不撤、复利引擎不中断，单次仓位减幅小、赎回费低）；「卖成本·留利润」则卖出成本、剩余为
利润免费仓位（适合快速回收本金、降低单基金敞口）。勾选批次确认后自动写入台账卖出记录
（备注=定投止盈·xx）并标记**该批次已止盈，之后不再参与计算**；其余未达线批次每次检测时
自动重新计算。

> **只输一个总市值准不准？** 不准确——它只能参与评分与调仓金额计算，无法定位
> 「入场高点」，20% 移动止损与 CPPI 回撤都算不出来（系统会提示需日期/成本/收益率）。
> 补上「买入日期」后按单笔近似，多笔买入/定投/中途卖出的持仓，入场高点回撤会被算歪
> （反推日期时可能严重低估，见 `docs/016452与持仓诊断分析.md` 的量化演示）。
> 系统在检测到「收益率反推跨度过大（疑似多笔/定投）」时会给出 ⚠ 告警并建议改用台账；
> **多笔/定投持仓请使用操作台账（每笔 代码 买/卖 日期 金额），FIFO 精确核算**，
> 那时你填的市值只作为锚定微调，不再决定曲线形状。

## 使用详解

### 页面六大区块（从上到下的推荐看法）
1. **大盘水位计 + regime**：先看它定总仓位。≥90% 收手 / 20-90% 按榜操作 / ≤20% 左侧模式
2. **估值地形**：12个风格+行业指数的五年PE分位，找洼地
3. **全市场扫描**：点按钮 → 后台爬取+深算（首次约4-6分钟, 当日缓存后约40秒）
4. **评分榜单**：可按总分/估值/动量排序、按评级/通道筛选、搜索；点击任意行进瀑布
5. **单基金透视**：任意代码 → 实时爬取+完整瀑布（新发基金会提示历史不足）
6. **持仓批算**：粘贴你的支付宝持仓代码（每行一个）→ 批量出分

### 榜单覆盖范围（不是全部基金！）
全市场 27,417 只 → 类型过滤(偏股/普通股票/指数股票/灵活配置/海外指数QDII, 剔除C/E重复份额)
≈ 4,630 只 → 要求近3年业绩存在(≥3年牛熊窗口) → **双通道抽 550 只深算**：

> **海外指数 QDII 通道（V3.9）**：`指数型-海外股票`（纳斯达克100/标普500/德国DAX等被动QDII，
> 约50只满足主池门槛）已并入扫描池，由 `config.SCAN_INCLUDE_OVERSEAS_INDEX` 控制（默认开启）；
> 主动型 QDII（QDII-普通股票/混合偏股等，风格归因差）仍排除。
> 此前该类基金只在「单基金透视」可查、永远进不了榜单——例如 016452 南方纳斯达克100(QDII)A
> 近3年 +69.8%，解禁后直接以 Strong Buy 上榜。

**分市场榜单（V3.9）**：榜单按 `region` 分 **🇨🇳 A股榜 / 🌐 海外榜**（右上角切换，
旧扫描结果按基金类型自动归类）。⚠ **两市场分数不在同一参照系，不可横向比较**
（估值口径/动量子集/风控锚不同）——先定 A股 vs 海外 的配置比例，再在各自榜单内选。
海外指数建议"配置思维"（长期+定投、申赎摩擦大、汇率敞口），A股按"信号思维"
（本系统完整闭环+止损纪律）。

**买入候选（V3.9 推荐逻辑）**：持仓诊断的「候选买入」按分层纪律生成——
① 不跨市场混比：A股/海外**各自按 S 降序**，跨市场 S 高者先取；② **海外配额**：
海外候选最多占 `STRAT_OVERSEAS_SLOT_CAP=3` 槽（10 槽中约 30%，防单边堆满）；
③ **重复度过滤（三档）**：**Tier0 复制盘**——与任一持仓/已选候选的 RBSA 暴露
L1 距离 ≤`STRAT_CLONE_L1=0.02` 判为同策略孪生产品（如 001801 达欣 vs 001417

顺位推荐其它风格（被排除候选完整列出 代码/重叠度/原因及占用者）；持仓凡
top1≥0.15 实质暴露即占用其簇名额，持仓与候选同口径（如持有 519770 不再
推荐同簇的 013107）；
④ 市场内按 S 高者优先。扫描榜单落盘 `rbsa`（JSON）供重复度计算；旧榜单自动
降级（提示重新扫描后生效）。**定投频率支持 每日/每月/每两周/每周**。
- **右侧池**：近3年收益前 N 名（默认400）——强势/绩优候选，捕捉真Alpha与顺风趋势
