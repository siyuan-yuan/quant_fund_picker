# 量化选基系统 V4 研究实验总计划与执行记录（2026-08-31 起）

> **总纲**：
> 1. 本文件是"实验协议 + 执行记录"二合一：每项研究预先登记假设与判定规则，
>    完成后把**客观结果**写回状态表，并标记 ✅(采纳) / ❌(否决) / 🔶(噪声/无效) / 🔄(进行中) / ⬜(未开始)。
> 2. **不预设任何改进是好的**。每个结论必须基于严格的大样本真实数据实验；
>    实验否决的改动同样入库（归档为 ❌，附统计量），防止日后重复试错。
> 3. 数据口径：**全基金池（本地缓存全部有净值文件的基金）+ 严格 Point-in-Time**。
>    任何决策日 d 只允许使用 d 日及以前披露的数据（净值截断、PE 截断、经理/档案回测模式禁用）。
> 4. 裁决门（统一）：单因子 IC 门 = |IC|>0.05 且配对 t>2（跨决策日）；
>    模型级改动门 = 端到端回测 Calmar 与 MaxDD 相对基线**双改善**且全历史 + 近3年两个窗口都成立。
> 5. 每个研究产物（面板 CSV、报告 MD）保存到 `output/p1/`、`output/p2/`…，报告副本存 `docs/`。
>    复现命令随每项登记，保证任何人可重跑。

### 0.2 严格 PIT 规则（面板构建必须满足）

1. 决策日 = 每月最后一个自然日（2013-01-31 → 2026-03-31，共 160 个），与 V3.8 执行层月度打分一致。
2. 基金 f 在决策日 d 合格 ⇔
   (a) d 日及以前净值行数 ≥ 800（≈3 年，与引擎 `min_days=800` 一致）；
   (b) 最后披露日 ≥ d−7 天（停更视为清盘/不可交易）；
   (c) 基金类型（今日名录）∈ 股票类 5 型且非 C/E 份额。
3. 评分一律 `score_fund(code, as_of=d, bt=True)`：净值/PE/水位全部截断至 d；
   经理任期/AUM/档案类非 PiT 数据禁用（引擎 bt 模式语义）。
4. 每决策日合格数 > 500 时，按**固定种子**（seed=决策日 YYYYMMDD 整数）随机抽 500 只
   （IC 等截面统计量在随机抽样下无偏；早期小池全取）。
5. 前瞻收益 fwd1/fwd3/fwd6 = 决策日后 21/63/126 个净值日的复权净值收益率，只用 d 之后的数据；
   不足 horizon 记 NaN（尾部约 1.5 年部分缺失，按 horizon 各自 dropna）。
6. 已知局限（如实披露，不掩盖）：
   - **幸存者偏差**：缓存只含现存基金 → 本阶段一切回测/IC 是**上界口径**；
     T0.2 补齐已清盘基金后必须重跑并报告差异。
   - **类型时点**：基金类型用今日名录（本地无历史类型快照），类型发生过变更的基金存在轻微时点错配；
     T0.1（Tushare fund_basic 历史）补齐后复核。
   - 抽样池上限 500：截面 ≥500 的日期使用种子抽样（可复现、无偏）。

### 0.3 统计裁决门（全阶段统一）

| 层级 | 门 | 说明 |
|---|---|---|
| 单因子 | 月度 IC（Spearman）均值 \|IC\|>0.05 且 t=mean/(sd/√n)>2 | n=决策月数；另报 5 分位多空价差辅助判读 |
| 因子间 | 增量 IC：对已有因子正交残差后再测 IC，t>2 才承认"新信息" | 防同源信号重复计分 |

### P1-1 三因子体检
- **假设**：H0=三因子各自含独立预测信息；H1=存在部分因子在多数时段 IC≈0 或与其他因子同源。
- **步骤**：
  1. 逐决策月、逐因子（val_pct 取反向=便宜度, wr, dc, r4, r7, R_MDD(取负=安全度),
     以及引擎 F_value/F_alpha/F_momentum/S_total）计算截面 Spearman IC，对 fwd1/fwd3/fwd6 三个 horizon；
  2. 汇总：IC 均值、t、ICIR（mean/sd）、正 IC 月占比、5 分位（Q5−Q1）月均价差；
  3. 衰减曲线：同一因子对 fwd1/fwd3/fwd6 的 IC 序列（检验 4M-1M 窗口选择的合理性）；
  4. 因子两两相关：逐月截面秩相关取均值矩阵（含 2015-2019 / 2019-2026 分时期）；
  5. 分时期贡献：按年度分组重复 1，输出因子×年度 IC 矩阵（定位各因子"干活"的行情段）；
  6. 分组稳健性：主动 vs 被动、A 股 vs 海外、n≥30 与 n≥100 子集分别报告。
- **判定**：不预设结论；输出全部数字。IC t<1 的因子标记 🔶 供 P1-2 处理。
- **产物**：`output/p1/f1_1_ic_table.csv` + `docs/P1_1_因子体检报告.md`。

### P1-2 FWL 正交化与权重裁决
- **假设**：H0=现行 0.40/0.35/0.25 权重（含未正交原始因子）已是最优线性组合；
  H1=正交化后重配权可提升合成 IC。
- **步骤**（全部预登记，无事后挑选）：
  1. 顺序固定为 value→alpha→momentum（与现行合成顺序一致），逐决策月做 FWL：
     a⊥ = α 对 v 回归残差；m⊥⊥ = m 对 [v, a⊥] 回归残差（秩空间操作，逐月独立）；
  2. 对比四种合成（均用 fwd6 主 horizon，fwd1/fwd3 复核）：
     S0 = 现行原始因子×0.40/0.35/0.25（复现基线，校验与引擎 S_total 一致）
     S1 = 正交因子×**同一** 0.40/0.35/0.25 权重
     S2 = 正交因子×**各因子|IC6|归一化**权重（IC 加权，预登记规则，非优化）
     S3 = 仅保留 IC t≥2 的因子，其余权重重分配
  3. 统计：各 S 的月度 IC 均值/t、S1/S2 相对 S0 的**配对差 t 检验**（逐月差值序列）；
     全历史 + 近 3 年（2023-04→2026-03）两个子窗口分别报告；
  4. 敏感性：对 fwd1/fwd3 重复 2-3（防止单一 horizon 侥幸）。
- **判定**：仅当 S1 或 S2 的配对差 t>2 且两窗口同向时，判定"权重应改"并给出新权重；
  否则判定"现行权重已验证"，归档 ✅（维持现状也是结论）。
- **产物**：`output/p1/f1_2_orthogonal.csv` + `docs/P1_2_正交化与权重裁决报告.md`。

### P1-3 动量窗口敏感性
- **预登记变体**（均在面板构建时落盘，零额外算力）：
  现值 r4=4M-1M、r7=7M-1M；变体：r3s1(3M-1M)、r3s0(3M 不剔除)、r4s0(4M 不剔除)、
  r4s2(4M-2M)、r7s2(7M-2M)、r12s1(12M-1M)。
- **步骤**：
  1. 每个窗口变体单独作为动量因子测 IC（fwd1/3/6，月度 t）；
  2. 双窗组合 M=0.6·rank(a)+0.4·rank(b)（现行 M1 公式）在变体对 (r4,r7)、(r4s2,r7s2)、
     (r3s1,r7)、(r12s1,r7) 上重测合成 IC；
  3. 5 分位多空价差对比（动量因子尾部区分度）。
- **判定**：仅当某变体相对现值 (r4,r7) 的配对差 t>2 且两窗口同向才建议改窗；否则维持 4M-1M/7M-1M。
- **产物**：`output/p1/f1_3_momentum_windows.csv` + `docs/P1_3_动量窗口敏感性报告.md`。

### P1-4 风险惩罚项的因子化复核
- **假设**：H0=R_MDD/任期/集中度/规模作为乘法惩罚已是最优用法；
  H1=其中部分量作为截面因子（加性合成）比乘法惩罚更有效。
- **步骤**：
  1. 将 R_MDD（取负）、top3_conc（取负）、smallcap_exp（取负）当因子测 IC（fwd1/3/6）；
  2. 与现行 S_total 的残差做增量 IC 检验（S 已含其惩罚信息，若增量 IC 仍显著 → 用法可改）；
  3. 乘法 vs 加性：把 S0 与"S0'（去掉对应惩罚改加性）"做端到端对决（月度回测协议同 P1-2 S0）。
- **判定**：同 P1-2 配对差 t>2 且双窗口同向才改。
- **产物**：`output/p1/f1_4_penalty_factor.csv` + `docs/P1_4_惩罚项复核报告.md`。
