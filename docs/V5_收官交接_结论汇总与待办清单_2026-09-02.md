## 2. 实测结论（客观数字，SURV-ADJ 口径）

### 2.1 A 链 HAC 复核：采纳链无一翻黑
- **R3.1**：全因子翻转 4/39，分组翻转 6/35。翻转项：`value fwd3`(−2.16→−1.67)、`alpha_ir fwd6`(2.41→1.30)、`mom4 fwd3`(2.56→1.91)、`eng_value fwd3`(−2.24→−1.72)。
- **R3.2**：`P12_S1_正交_原权−S0` fwd3(−2.56→−1.91)、fwd6(−3.12→−1.95) 翻转；`P12_S2_正交_IC权−S0` fwd6 (−4.05→−2.45) **存活**。
- **R3.3**：`P22_ntuw252` fwd3 IC +0.0504 t_HAC 2.87、fwd6 +0.0505 t_HAC 2.33 **存活**；fwd1 翻转。P2-A 配对差全部不显著。
- **R3.4**：生产 V3.7(S_eng) − V0 IC +0.0209 t_HAC 3.32，**0 处翻转**。
- **结论**：现行采纳链在 HAC 严口径下未出现"由显著变不显著"的采纳级翻黑；**维持现状**。

### 2.2 执行口径分解（B2.x，唯一权威基线，禁再改口径）
R0 +5.08% / MaxDD −22.4% → R1 +8.59% / −18.7% → R2 +10.73% / −18.9% → R3 +10.84% / −18.5%。
延迟敏感性：delay=0 +9.55%、delay=1 +10.84%、delay=2 +10.74% → **T+1 执行不是"甜点参数"，延迟 2 天也不塌**，稳健。

### 2.3 C1 / C2 裁决（双门，均维持现状）
- **C1（去掉 MDD 惩罚）**：H1 OOS 配对 IC t_HAC = **1.11 未过**；H2 ΔCAGR +1.36pp、ΔMaxDD −0.01pp 过。**双门未同时通过 → MDD 惩罚保留**。
- **C2（动量平滑 M2 替 M1）**：H1 t_HAC = **−0.47 未过**；H2 ΔCAGR **−1.45pp**、ΔMaxDD **−4.31pp** 皆负。**否决 M2，维持 M1**。

### 2.4 R3.5 模型动物园（#24，本轮核心新结论）
- 样本：SURV-ADJ 半池 **110/217 只**，面板 **12,383 行 × 138 月末**，全体配置共同冷启动 **2016-04-30**。
- **对照臂 V3.7 规则分**：full n=123，IC **+0.1011**，t_naive 5.41，**t_HAC 3.32**（显著）。w2019 子窗 IC +0.0989，t_HAC 2.32。
- **5 个 fwd6 ML 决赛配置**（lasso/enet/svrlin/lasso-F3/huber）：修正后 IC 0.0473 ~ 0.0640，**t_HAC 1.06 ~ 1.63，全部不显著**。
- **配对差 V3.7 − ML**：t_HAC 1.10 ~ 1.72，**全部未过 2.0**。
- **判定**：三种合法结论中落在 **「无统计区分」**一档 —— 既不能宣称 V3.7 显著优于 ML，也不能宣称 ML 反超。
  **ML 腿不构成候选，维持现状（台账 C7）**。
- **F4 前视爆炸半径实测证实**：`huber F2 fwd12_z` 把标签窗从 q−6M 改到 q−12M 后，
  历史 IC **+0.0773 → 修正后 −0.0842（t_HAC −2.00）**，V3.7 与其配对差 t_HAC **3.36**。
  即：**一处标签窗前视足以把一个"看似最好的模型"翻成显著为负**——这是本轮最有价值的方法论证据。
- **窗口口径披露**：因共同冷启动 2016-04-30 晚于 w2015 阈值 2015-01-31，**full 与 w2015 逐行相同**（已验证 `True`），
  故 R3.5 实际只有 2 个独立窗口而非 3 个，报告中不得宣称"三窗一致"。

#   11 组 = 种子{1..5}×maxn{500,1000} + 全取×1，每组 159 月

#   本机 2 核实测外推：14–18h 墙钟；maxn=1000 与"全取"组显著更重

## 6. 有助于优化模型的改进方向（基于本轮实测，非预设）

> 以下每条都注明"证据强度"。**没有一条可以在 FULL-PIT 打通前直接上生产**。

1. **【证据强，方法论层】把"标签窗前视"列为一级红线检查项。**
   实测：`fwd12` 一处标签窗错配就把 IC 从 +0.0773 打到 −0.0842（t_HAC −2.00）。
   建议：在 `_build_ml_panel.py` 与所有打标脚本入口加**断言**——标签起点必须 ≥ 特征快照日 + 执行延迟，
   并把"标签窗 / 特征窗 / 执行延迟"三元组写进每份产物的 manifest 头。这是**零成本、高收益**的护栏。

2. **【证据中，模型层】ML 腿短期不值得继续投入，除非先扩样本。**
   R3.5 的 110 只 / 12,383 行 / 冷启动 2016-04 的样本量下，5 个决赛配置 t_HAC 全在 1.06–1.63，
   **不是"ML 不行"的证据，而是"样本不足以区分"的证据**。
   建议顺序：先打通 FULL-PIT 扩到全池（预计样本量 ×10 量级），**再**重跑 R3.5；
   在此之前继续调 ML 超参属于在噪声里挖矿。

3. **【证据中，因子层】`ntuw252`（252 日水下时间占比的负向）是本轮唯一稳健存活的新因子线索。**
   fwd3 IC +0.0504 t_HAC 2.87、fwd6 +0.0505 t_HAC 2.33，HAC 后仍显著且跨窗一致；fwd1 翻转说明它是**中周期**信号。
   建议：作为独立候选走完预登记 → 冻判门 → FULL-PIT 复核流程，**不要**直接塞进 V3.7 权重。

4. **【证据中，风控层】MDD 惩罚保留是对的，但它买的是"防守"不是"收益"。**
   C1 实测去掉 MDD 惩罚 CAGR +1.36pp 而 MaxDD 几乎不变（−0.01pp）。
   这说明当前 MDD 惩罚在 SURV-ADJ 池里**没有兑现风控价值却在吃收益**。
   但 H1 门未过（t_HAC 1.11），所以维持现状是正确处置。
   建议：把它列为 **FULL-PIT 打通后第一批复核项**——幸存者偏差恰恰会系统性低估回撤，
   全池下 MDD 惩罚的价值很可能被重新证实（或彻底否定），这是个高信息量的实验。

5. **【证据强，工程层】执行口径已经稳了，不要再动。**
   B2.3 显示 delay=0/1/2 的 CAGR 为 +9.55%/+10.84%/+10.74%，非尖峰；
   S6.2 243 格邻域基线分位 82%、CAGR 全域 [+5.43%, +12.53%]。
   参数处在平坦区中上位，**继续调参的期望收益低于过拟合风险**。§2.2 口径已封，禁再改。

6. **【证据弱，待验】平滑类变体（V1/V2/V3/V5）方向一致为正但幅度小。**
   R3.4 中 alpha 平滑 +0.0091(t_HAC 2.57)、mom 平滑 M1 +0.0151(2.79)、全平滑 +0.0176(2.34)，
   而 value 平滑为负 −0.0035(−1.08)。
   建议：**不要做"全平滑"**（它的增益基本来自 mom+alpha 两条腿），把 value 排除在平滑之外；
   但幅度都在 1–2pp IC 量级，需 FULL-PIT 复核才值得动权重。

7. **【治理层】把"静默绿灯"当故障处理。**
   M12（产物缺失 → 测试 skip 而非 fail）+ 三次沙箱重置的联合效应是：
   **本地未推送的 commit 与未入 manifest 的产物等于不存在**。
   建议固化两条：①每批实验结束立即 `commit + push`；②任何结论落地前先跑 `v5_manifest.py` 把产物指纹入库。
