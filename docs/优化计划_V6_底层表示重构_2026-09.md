## 0. 立项判断（本计划的存在理由）

### 0.1 三层结论（评审意见 §15 的仓库侧确认）

| 问题 | 结论 | 仓库内证据 |
|---|---|---|
| V3.7 是否已无价值？ | **否**。它确实从现有数据中抽到了稳定信息 | 修正后半池面板 V3.7 自身 IC ≈ +0.101，HAC t ≈ 3.32（R3.5 通道） |
| V3.7 架构是否接近局部最优？ | **是，且证据强** | 35 个评分变体 / 243 格执行网格（S6.2 基线分位 82%，跨维极差 ≤±1.9pp）/ 66 组模型动物园（C7：ML 腿 HAC IC 本身不显著，配对差不显著）/ CSCV PBO = 0.90、无配置 DSR 达 0.97（P4 审计） |
| 整个选基问题是否到天花板？ | **完全没有** | 未被系统探索的是 **信息集 / benchmark 测量模型 / 标签定义 / 模型结构**，而非超参数 |

**一句话定位**：现在的瓶颈不是 $f_\theta$ 不够强，而是 $X$ 与 $Y$ 的定义本身。
信息论上限约束 $I(Y; f(X)) \le I(Y; X)$——在 $X$ 不变时更换逼近器，模型动物园的结果（复杂模型不优于规则模型）是**预期内的正常结果**，它证明的是"当前 V3 信息集下函数族不再是瓶颈"，**不能外推为"ML 路线封死"**。

### 0.2 本计划最核心的技术命题（V6 的第一刀）

`engine.py` 现状（实读）：

```python
w        = rbsa.rbsa_weights(ret, idx_ret)          # 近 60 日 × 错位 {0,5,10} 平均，positive Ridge
bench    = (idx_ret[w.index] * w).sum(axis=1)       # ← 同一组 w_q 套到整条历史序列
active   = (ret - bench).dropna()                   # ← 再拿它算过去 ~3 年 rolling IR / downside capture
```

即当前 F_alpha 的测量模型是

$$r^{bench}_t=\hat w_q^\top r^{index}_t,\qquad \forall t\in[q-3y,\;q]$$

这**不是 look-ahead**（$\hat w_q$ 只用 $\le q$ 的数据），但是一个**严重的模型错设（model misspecification）**：
**用"今天的风格"解释"过去三年的收益"**。基金的风格漂移收益（消费→新能源→AI）会成片掉进残差，被 F_alpha 记为"经理 alpha"。

这一条同时可以解释两个至今未被区分的现象：

- **解释 A（现行）**：F_alpha 体制敏感（2015 好 / 2019 差 / 2023 好 / 2024–25 连负，downside capture 主拖累）；
- **解释 B（未检验）**：F_alpha 的 **measurement model 不稳定**，年际变号有一部分是估计误差而非真实 skill 变化。

**V6 的 T1 实验就是把 A 与 B 分离**。理由：如果 alpha 本身测错了，后续所有 ML 只是在学一个含噪的 target/feature——**T1 的优先级高于 FULL-PIT 后重跑 LightGBM**。

### 0.3 与 V5 的关系（明确边界）

- V5 **不废止**：其统计门（§0.3）、PIT 规则（§0.2）、DSR/CSCV/PBO 台账、翻案规则在 V6 全盘继承。

## 1. V6 总目标与成功判据

### 1.1 目标

在 **FULL-PIT 口径**下回答三个此前无法回答的问题：

1. **Q1（测量）**：把静态 60 日 RBSA 换成显式时变暴露路径 $\beta_{i,t}$ 后，F_alpha 的稳定性与预测力是否提升？

### 1.2 V6 级别的成功判据（预登记，双向）

**V6 判定为"成功打开第二曲线"**，当且仅当在 FULL-PIT 口径下同时满足：

- (a) 新信息集下的 baseline（ElasticNet 或 LightGBM，排序/分类目标）对 V3.7 的 **配对 IC 差 HAC t > 2**，且全期 + 近 3 年双窗同向；
- (b) 端到端 **Calmar 与 MaxDD 双改善**，Holm 校正后仍显著；

### T1 — 动态 benchmark：F_alpha 的测量模型重构【V6 技术核心】

- **修复对象**：`engine.py:109-122,146-152` 的静态 $\hat w_q$ 反套历史；C3（alpha_ir 依据弱化告警）的根因候选。
- **模型设定**

  现行（V3.7）：
  $$r^{bench}_{i,t}=\hat w_{i,q}^\top f_t,\quad \hat\beta_{i,t}\equiv\hat\beta_{i,q}$$

  V6 候选：
  $$r_{i,t}=\alpha_{i,t}+\beta_{i,t}^\top f_t+\epsilon_{i,t},\qquad
    \beta_{i,t}=\beta_{i,t-1}+\eta_{i,t},\ \ \eta_{i,t}\sim N(0,Q_i)$$

  由此得到**真正的历史 abnormal return**：
  $$AR_{i,t}=r_{i,t}-\hat\beta_{i,t|t}^\top f_t$$

  **PIT 硬约束**：$\hat\beta_{i,t|t}$ 必须是**滤波值（filtered）而非平滑值（smoothed）**——在 $t$ 时刻只允许使用 $\le t$ 的信息。RTS smoother 只允许出现在诊断图里，**禁止进入任何特征/标签**（违反即产物作废）。

- **候选实现（三臂，全部与现行基线并列评测）**

  | 臂 | 方法 | 关键参数 | 备注 |
  |---|---|---|---|
  | B0 | **现行静态 60d Ridge**（对照臂） | `RBSA_WINDOW=60`, offsets {0,5,10}, `RIDGE_ALPHA=1.0` | 不动一行 |
  | A1 | **Kalman Filter 时变 β** | $Q=\sigma_\eta^2 I$，$\sigma_\eta$ 由 EM 或按 {1e-6,1e-5,1e-4} 三档预登记；单纯形投影保证 $\beta\ge0,\sum\beta=1$ | 主推臂 |
  | A2 | **滚动 Ridge 路径**（廉价对照） | 每月重估 60d/120d 权重，只用于当月区间 → 拼接成路径 | 用于区分"时变收益"与"KF 技巧收益" |
  | A3 | **结构突变检测**（诊断臂） | Bai–Perron / CUSUM 检出 style break 点，分段常数 β | 只用于回答"漂移是否显著存在"，不入产 |

  **非负 + 和为 1 的处理**：KF 每步后做单纯形投影（projected KF）；投影前后残差差异作为诊断量披露。

- **假设（双向，逐条可被证否）**
  - **H1-1**：A1/A2 的 $AR_{i,t}$ 序列相对 B0 的 active return，**风格残留显著降低**——检验量：$AR_{i,t}$ 对同期风格指数收益的滚动回归 $R^2$（越低越好）与残余 β 的绝对值之和。
  - **H1-2**：基于 $AR$ 重算的 F_alpha（IR winrate + downside capture）**IC 与 HAC t 改善**，且年际符号翻转次数下降。
  - **H1-3（关键的解释分离）**：若 A1 下 F_alpha 的 2024/2025 负值**依然存在**，则支持"体制敏感（解释 A）"；若显著缓解，则支持"测量模型不稳（解释 B）"。**两个结果都写入结论，不预设方向。**
  - **H1-4**：style break 在样本中普遍存在（A3 检出比例显著 > 0），从而"固定暴露"假设被数据拒绝。

- **步骤**
  1. 新增模块 `dyn_rbsa.py`（不改 `rbsa.py`，保证 B0 逐位可复现）：`kalman_beta_path()` / `rolling_beta_path()` / `break_test()`。
  2. `engine.py` 增加 `bench_mode ∈ {static, kf, rolling}` 开关，默认 `static`（生产不变）。
  3. 在 T0 面板上，为每只基金生成 $\beta_{i,t}$ 路径与 $AR_{i,t}$ 序列，落盘为 parquet（约 5k 基金 × 日频，预算见 §6）。
  4. 用 $AR$ 重算 `factors.rolling_ir_winrate` / `factors.downside_capture` → F_alpha^dyn。
  5. **因子层评测**：F_alpha^dyn vs F_alpha^B0 的配对 IC 差（fwd1/3/6），HAC（L=1/3/5）。
  6. **端到端评测**：仅替换 F_alpha，其余权重/执行**一律冻结**（避免与禁区混淆），跑 `strategy_bt.py`。
  7. **诊断**：$\beta$ 路径可视化抽样 20 只（含已知风格漂移基金）；A3 break 比例统计。

- **判定门（预登记）**
  - **因子门**：配对 IC 差 HAC t > 2，且全期 + 近 3 年双窗同向 → 通过；
  - **端到端门**：Calmar 不降、MaxDD 劣化 ≤ 2pp（沿用 C1/C2 口径）；
  - **稳健门**：结论在 $\sigma_\eta$ 三档中至少两档同向，且 A1 与 A2 方向一致（若只有 A1 成立而 A2 反向 → 判为"KF 特有拟合"，降级为诊断，不入产）；
  - 三门全过 → **F_alpha 改用动态基准（进入生产候选）**；任一不过 → 维持 B0，但 H1-3 的解释性结论**仍然入库**（这是 T1 的独立价值）。

- **产物**：`dyn_rbsa.py`、`output/v6/t1_beta_paths/`、`output/v6/t1_alpha_compare.csv`、`output/v6/t1_break_stats.csv`、`docs/V6_T1_动态基准报告.md`
- **状态**：⬜

### T2 — 目标函数重构：style / skill 分离 + 排序化

- **修复对象**：`_build_ml_panel.py` 的 `fwd{3,6,12}_z` / `fwd{3,6,12}_rk` 单一标签族。
- **问题陈述**：现行标签由复权净值直接算 $R^{fund}_{t\to t+h}$ 后做截面 z / rank。若未来半年 AI 大涨，一只 AI 暴露高的**平庸基金**也会成为正样本 → 模型可能在学"哪种风格会涨"，而非"同风险暴露下谁更优"。这不等于错（style timing 本身可以是 alpha 来源），但**必须拆开**。
- **三套并行 target（依赖 T1 的 $\hat\beta_{i,t}$）**

  $$Y^{raw}_{i,t}=R^{fund}_{i,t\to t+h}$$
  $$Y^{style}_{i,t}=\hat\beta_{i,t}^\top R^{index}_{t\to t+h}\quad(\text{可预测的赛道分量})$$
  $$Y^{skill}_{i,t}=R^{fund}_{i,t\to t+h}-\hat\beta_{i,t}^\top R^{index}_{t\to t+h}$$

  **注意**：$\hat\beta_{i,t}$ 取**决策日的滤波值并在持有期内冻结**（决策日可得），否则引入前视。持有期内 β 漂移造成的偏差作为已知近似，量化披露。

- **目标形态（三选一并列评测，不是二选一）**
  1. 回归：截面 z（现状）；
  2. **分类**：$P(\text{基金未来跑赢其动态基准} \mid X_t)$，即 $\mathbb{1}[Y^{skill}>0]$；
  3. **learning-to-rank**：LambdaRank / pairwise，目标直接对齐 Top-10 决策（评价用 NDCG@10、Top-decile 命中率）。

- **组合方式（最终形态）**
  $$Score_t=\lambda_t\,Score^{style}_t+(1-\lambda_t)\,Score^{skill}_t$$
  $\lambda_t$ 的三种设定**必须预登记后固定**：(i) $\lambda\equiv0.5$；(ii) $\lambda$ 由 water/regime 状态映射；(iii) $\lambda$ 由两腿近 12 月 OOS IC 动态加权。**禁止事后择优**——三档全部报告。

- **假设（双向）**：H2-1 skill 腿单独具备 HAC 显著预测力；H2-2 style 腿单独具备；H2-3 组合优于任一单腿；H2-4 ranking/classification 目标优于回归目标（IC / NDCG@10 双指标）。四条均可为否。
- **判定门**：各腿因子门（HAC t>2）+ 组合端到端双改善门；ranking vs 回归的比较用**配对差序列**，禁止比较两条各自的 t 值（V5 F2 教训）。
- **附带产出（本阶段最重要的解释性资产）**：**V3.7 历史收益的 style / skill 分解表**——按年份、按基金类型给出两者贡献占比，回答"过去赢在押赛道还是选人"。
- **产物**：`v6_panel.py`（新面板构建器，替代 `_build_ml_panel.py`，保留后者供对账）、`output/v6/t2_targets.parquet`、`output/v6/t2_style_skill_attrib.csv`、`docs/V6_T2_标签重构报告.md`
- **状态**：⬜

### T3 — 信息集扩张：从 return-centric 到 fund-centric【S 级】

- **问题陈述**：现行 $X$ 的独立信息维度只有三四类，且高度 return-centric：

  | 信息来源 | 当前体现 | 是否价格衍生 |
  |---|---|---|
  | 基金历史净值 | momentum / trend / MDD / water | 是 |
  | 指数历史收益 | RBSA / F_alpha | 是 |
  | 指数估值 | F_value | 半（经 RBSA exposure 传入） |
  | 基金资料 | AUM、经理任期、集中度惩罚 | 否（但极稀疏，且回测中 `bt=True` 时任期/AUM 直接豁免） |

  momentum / trend / MDD / IR 本质都是基金价格序列的函数；RBSA 是基金价格与指数价格的函数；value 又通过 RBSA 传入。**整个系统几乎是单一信息源的多种变换。**

- **T3.1 新特征清单（分批引入，每批单独预登记）**

  | 批次 | 特征 | 定义要点 | PIT 风险点 |
  |---|---|---|---|
  | B1 资金流 | `flow`、`flow_3m`、`flow_vol`、`flow_shock`（flow 对自身历史的标准化残差） | 由季报份额 × 净值反推：$flow_t=AUM_t-AUM_{t-1}(1+r_t)$ | **季报披露滞后**：只能在披露日之后可用（约 +15~45 天），必须用 `known_at` 而非报告期 |
  | B1 规模 | `AUM`、`ΔAUM`、`log_size`、`size_rank` | 同上 | 同上 |
  | B2 费率/运作 | `mgmt_fee`、`custody_fee`、`total_expense`、`turnover_ratio` | 年报/半年报 | 披露滞后 + 中途调费事件需按生效日 |
  | B2 经理 | `manager_tenure`、`manager_change_6m`、`n_managers`、`manager_prior_track` | 变更公告日为可得日 | **禁止用今日档案回填历史**（现行 `bt=True` 已豁免，V6 需真实历史快照，取不到就保持缺失+打标） |
  | B3 家族/年龄 | `family_size`、`family_avg_rank`、`fund_age`、`is_newborn` | 名录快照 | 依赖 T0.2 |
  | B4 回归诊断量 | `rolling_alpha`、`alpha_tstat`、`beta_loading_tstat`、`regression_R2`、`resid_vol`、`skill_vol` | 由 T1 的 $AR_{i,t}$ 直接派生 | 依赖 T1 |
  | B5 状态条件 | `alpha_decay`、`alpha_hit_rate`、`downside_alpha`、`state_conditioned_alpha` | 同上，按 water/regime 分段 | 依赖 T1 |

- **T3.2 缺失值纪律**：V5 §0.2-5 继承——只允许逐日截面或扩展窗统计量，**禁止全样本统计量**（修复 `impute_features` 的 `gmed` 全期中位数兜底）。新特征早期缺失严重（2006–2012），按 T0.4 稀疏规则处理并逐年披露覆盖率。
- **T3.3 单因子体检**：每个新特征按 V5 §0.3 单因子门（|IC|>0.05 且 HAC t>2）+ **因子增量门**（对既有 V3 因子族正交残差后仍 HAC t>2）双检。未过增量门的特征**不进 T4 特征集**（防同源重复计分）。
- **T3.5 — ntuw252 复测（A 级遗留）**：C4 登记的低波因子，HAC 后 fwd3 t=2.87 / fwd6 t=2.33 / fwd1 已失效 → 形态上像**中周期因子**。V6 内按 C4 原定协议在 FULL-PIT 面板做**相对既有因子的 residual IC**，通过则纳入 T4 特征集，否则归档。
- **判定门**：每批至少 1 个特征通过增量门 → 该批保留；整批不过 → 整批归档（并入 PBO 台账计数）。
- **产物**：`fund_fundamentals.py`（抓取+对齐）、`output/v6/t3_feature_health.csv`、`docs/V6_T3_信息集扩张报告.md`
- **状态**：⬜

### T4 — 极简 baseline：ElasticNet + LightGBM（排序/分类）

- **纪律（针对模型动物园的教训）**：本阶段**只允许两个模型族**（ElasticNet、LightGBM），**禁止再铺 sklearn 全家桶**。C7 已经证明：在信息集不变时铺模型没有信息量；V6 要检验的是"新 $X$ + 新 $Y$ 是否有增量"，**模型族必须固定以免混淆变量**。
- **协议**
  1. **严格 walk-forward**：训练截止 ≤ $q-hM$（修复 `_model_zoo.py:125` 对 fwd12 硬编码 6M 的错误）；扩展窗 + 至少 24 月冷启动，冷启动期从对比窗剔除（修复 M2）。
  2. **超参**：预登记网格 + 时间序列 CV（内层不得看外层年份）；LightGBM 用早停 + 固定 seed×5 取中位数报告。
  3. **对照臂**：V3.7 规则分（`S_v37`，等价于 `S_engine`，见 M15 注记）。
  4. **评价**：因子层配对 IC 差（HAC）+ NDCG@10 + Top-decile 命中率；端到端 Calmar/MaxDD/换手（C7 指出 ML 组合换手更高，本轮**换手率必须并列报告并计入成本**）。
  5. **消融（本阶段的核心信息）**：
     | 配置 | X | Y | 用途 |
     |---|---|---|---|
     | M0 | V3 特征 | fwd6_z | 复刻 C7（应当复现"无增量"） |
     | M1 | V3 特征 | skill 标签 | 隔离"标签重构"的贡献 |
     | M2 | V3+T3 特征 | fwd6_z | 隔离"信息集扩张"的贡献 |
     | M3 | V3+T3 特征 | skill 标签 + ranking | 完整 V6 |
     **只有 M3 > M0 且能从 M1/M2 看出增量来源，才算真正回答了 Q3。**
- **判定门**：§1.2 的 (a)(b)(c) 三条。

### T5 — 结构化：分层部分池化 / mixture-of-experts

- **问题陈述**：现在对**主动 A 股 / 被动指数 / 海外 QDII / 不同风格**基金使用同一主评分函数；虽有估值盲区、被动豁免等修补，核心函数仍共享。而实验已显示 F_alpha 在不同年份、A 股/海外、主动/被动间差异巨大。
- **设定**：目标 $E[Y\mid X,g,t]$，$g$ = fund type/style 组。采用**部分池化**而非独立模型：
  $$\beta_g=\beta_{\text{global}}+\delta_g,\qquad \delta_g\sim N(0,\tau^2)$$
  避免两个极端：每类单独训练（样本过少）/ 全体混训（机制混淆）。
- **候选**：(i) 分层线性（$\tau$ 由经验贝叶斯估计）；(ii) LightGBM + group 特征交互；(iii) 轻量 MoE（门控由 fund type + regime 决定，专家数 ≤ 4）。
- **判定门**：相对 T4 最优臂的配对差 HAC t>2 + 端到端双改善；且**分组样本数 ≥ 200 组·月**的组才允许拥有自己的 $\delta_g$，否则强制回落到 $\beta_{global}$。
- **前置条件**：T4 至少有一臂过因子门，否则 T5 冻结。
- **产物**：`output/v6/t5_hier.csv`、`docs/V6_T5_分层模型报告.md`
- **状态**：⬜

### T6 — 序列模型 / TFT【条件解锁，默认不做】

- **动机**：基金 skill 可能是 **episodic / state-dependent**——某经理的信号只在特定信息环境重现时才恢复预测性，这与 F_alpha "2015 好 / 2019 差 / 2023 好 / 2024–25 负"的形态吻合。
- **解锁条件（硬）**：T4 或 T5 中至少一臂通过 §1.2 (a)+(b)。**若 LightGBM 都吃不到增量，TFT 只会更容易过拟合**——届时 T6 直接归档为"不做"，并写明理由。
- **若解锁**：序列长度、特征分组（static/known-future/observed）、正则、seed×5、以及**与 T4 最优臂的配对比较**须先预登记。
