## 0. 总裁决

**该项目研究流程的规范程度显著高于同类个人量化项目**（预登记制度、DSR/CSCV/Holm 多重检验审计、失败实验归档、实现双轨校验、诚实披露幸存者偏差），但最终结论的**对外表述仍系统性强于底层统计证据**。存在 5 项 P0/P1 级缺陷，其中 2 项直接动摇 README 头部数字的有效性。

| # | 缺陷 | 级别 | 一句话裁决 |

- ✅ 方向性结论（"V4 神话是小池+前视假象 → 弃用"、"规则模型不劣于严格 walk-forward 的 ML"、"无变体值得采纳、维持 V3.8"）**总体有效**，且部分是在对对手方（ML）有利偏差下得出的，稳健性反而更强。

## 1. 审查发现详述

### F1（P0）执行层成交价未复权 —— 结构性口径错乱

**事实**：
- 信号层/IC 层：`engine.score_fund` 用 `adj = (1 + ret).cumprod()`（东财官方复权日增长率）计算 MACD/MA20/动量/回撤——口径正确。
- 执行层：`backtest_local.py:216`、`p3_backtest.py:96`、`strategy_bt.py:63`、`strategy_experiment.py` 四处回测的买卖成交价与逐日盯市全部用**原始单位净值 `nav`**。
- 单位净值在分红除息日下跌，官方日增长率回补。即**持仓期间的分红被记为亏损**。

**独立实证**（本次审查实测，随机抽 400 份缓存，357 只有效）：
- 净值变动与官方收益差 >1pp 的日期：357 只中 820 天；
- 典型案例：`160222` 2015-05-22，原始净值日变动 **−34.52%**，官方复权收益 **+2.62%**——任何基于原始净值的 20% 移动止损/CPPI 回撤检查会在该日**虚假触发**；
- 持仓影响量级：≥3 年样本 308 只，原始净值口径 CAGR 平均被低估 **0.59%/年**（中位 0.07%，P75 0.88%，**最大 12.6%/年**）。

**影响判定**：
- 所有"三本账"中的组合 CAGR/MaxDD/Calmar/胜率/盈亏比均非真实货币收益口径；
- 路径依赖规则（20% 移动止损、CPPI −15/−20/−25 档、危机禁买不受影响因其用指数）的触发序列被分红事件污染——P3 波次中诸如"棘轮陷阱 6 笔 churn −3,542 元"这类**笔级结论**可能含分红噪声；
- 变体间相对比较大体同源偏置（方向性裁决如 "cap25/30 否决" 大概率幸存），但**绝对数字全部需要重跑后重新发布**；
- 与 F（基准为价格指数）方向相反，两者**不可相互抵消使用**——基金分红留存率与指数股息率无同一性。
- 另注：晨星/卖方通行做法即复权净值成交；此缺陷属机构评审的一票否决项。

**修复**：成交价序列改为 `(1+ret).cumprod()`（对齐首日净值缩放即可），止损/CPPI 用同一复权序列。约 6 行改动 + 全量重跑。

### F2（P1）IC t 值未做重叠校正 —— 显著性系统性膨胀

**事实**：全项目统计量统一为 `t = mean/(sd/√n)`（`p1_analysis.py`、`wf_backtest.py`、`_model_zoo.py::ic_metrics`、`strategy_bt.py::ic_check` 等）。月度决策 × fwd6（126 交易日）标签 ⇒ 相邻月标签窗口重叠 5/6，IC 序列强自相关；朴素 t 以 n=235 计自由度，**有效样本量约 n/6~n/11**。

**量级估计**（6 期重叠、三角自相关近似：膨胀因子 ≈ h=6，上界 2h−1=11）：

| 报告值 | 朴素 t | 校正后期望 ≈ | 判定影响 |
|---|---:|---:|---|
| 动物园 V3.7 | 8.11 | ~3.3（区间 2.7–8.1） | 仍显著 ✅ |
| 动物园 Lasso（最优 ML） | 5.56 | ~2.3 | 勉强 ✅ |
| P1 eng_S | 7.77 | ~3.2 | 仍显著 ✅ |
| P1 动量 mom7 单因子 | 4.43 | **~1.8** | **跌破预登记门 t>2** ⚠️ |
| P1 eng_alpha | 5.72 | ~2.3 | 勉强 ✅ |
| P2 tuw252 | 3.97 | ~1.6 | 其"差 0.0004 未过 IC 门"的裁决不变，但论证更弱 |
| HP4A-3 OOS 配对差 | 2.50 (24个月) | **大概率 <2** ⚠️ | "判据通过→送 HP4A-4"这一中间门的稳健性存疑；所幸绑定裁决（HP4A-4 双门）是否决，**终局结论不变** |
| wf_backtest / factor_study V3.7 采纳证据 | 3.20/3.46（季度,重叠1期） | ~2.4–2.9 | 边界 |

**另一个同族错误**：以两条 IC 序列**各自的 t 值大小比较**裁决变体（README V3.7.1 "采纳组合 t=3.46 > 现行 3.20"、"软化 t=3.02<3.20 否决"）——这在统计上不成立（应比较配对差序列的 t：项目在 `rbsa_ew_study.py` 与 P1 系列中已经正确使用配对差 t，**标准不统一**）。

**修复**：全部 IC/配对差序列改用 Newey-West（L=5 月）标准误；历史门槛判定用 HAC 复核一遍并入库修正表。

### F3（P1）幸存者偏差：后期披露模范，早期标签错误

**事实链**：
- `backtest.py:34-40`：池筛选要求 `首净值 ≤2014-12-31 且 末净值 ≥2025-09-23`——这是**双向条件**：既是幸存者条件（活到 2025-09）又是资深条件。而注释写作 "**无幸存者偏差的随机池**"——事实错误。
- 该池支撑了 V3.6/V3.7 平滑化采纳（factor_study）、wf_backtest 的 t=3.2、veto/tenure/EW 研究、217 只种子池（`top100_history_pool.txt`，216 行+引擎注释 217）、模型动物园面板（`_build_ml_panel.py` 从 `bt_scores_cache` 重建 31,329 行）。
- PiT 模式（`backtest_local --pool-mode pit-top`）的"严格历史动态池"实为**今日幸存种子池上的当日 TopN**：信号时点无未来函数 ✅，但宇宙成员身份有幸存者偏差 ❌。`pit_universe.py`（真正接受历史快照、拒绝回退今日名录的严格框架）**是死代码**——全仓库无任何模块 import 它（grep 实证）。
- 值得称道：P1-P4 报告与计划 §0.2(6) 对该局限的披露是完整、前置的，且用外部锚定（清盘 288 只/86% 正收益）做了三情景区间估计（+9.0%~10.3%），并在 P4-4 把两口径隔离。**披露模范，但事实未闭环**：T0.2（已故基金净值）解锁前，一切绝对数是"趣味知识"而非"可下注的期望"。

**修复**：`build_pool` 注释改为"资深幸存池（收益上偏，顶面）"并在输出文件名/列名携带该标签；启用或删除 `pit_universe.py`；README "严格 PIT 全基金池" 改为 "**PiT 打分 × 幸存种子池动态 TopN**"。

### F4（P1）模型动物园：fwd12 目标真实前视 + 两处次要泄漏 + 结论与表格矛盾

**代码取证**（`_model_zoo.py`）：
1. **L125 `cutoff = q − 6M` 对所有目标硬编码**。fwd6/fwd3 目标干净 ✅；**fwd12_z 目标**（huber F2 fwd12_z，决赛配置之一）的训练样本 d∈(q−12M, q−6M] 的标签要到 d+12M = q+6M 才成熟——**最多偷看未来 6 个月**。报告标题宣称"无前视偏差"不成立；受污染的是该单一配置的 IC 0.0773 与其端到端结果。主结论（V3.7 vs 其余 65 配置）不依赖该配置，方向不受影响。
2. **L108 全样本中位数兜底** `gmed = out[c].median()`（逐日截面中位数 ✅，但全期兜底是 2006–2026 全样本统计量——轻度前视）。个案影响小，属审查必须点名项。
3. **screen→verify 同面板选择偏差**：决赛者按同一面板的 OOS IC 选优（winner's curse），verify 与 backtest 阶段复用同一历史——ML 数字整体**向上**偏。这反而强化了 V3.7 胜出的稳健性（对手被高估仍未赢）✅，但报告未声明此不对称。
4. **冷启动不对称（M2 根源）**：`min_q=8` + 6M 标签滞后期 ⇒ ML 首个预测约在面板第 13–14 决策月（≈2007-10-11）。期间（2006-09→2007-10，沪深300 约 +160%）V3.7 纯分可满仓而各 ML 配置空仓吃 2.5% 现金。**full 窗口对比因此无效**（V3.7 的 full 优势 8.70% vs 8.37% 完全可被该不对称解释）；公平窗口只有 w2015/w2019。
5. **报告内部矛盾**：§5.1 表格显示 w2015 窗口 lasso/enet w0.3 的 Calmar **0.30 > V3.7 的 0.27**，而 §一.2 与 §六写"3 个时间窗口**全部领先或并列第一**"——**事实错误**，需勘误。README 的摘要表反而忠实呈现了 0.27/0.30，但仍旧使用"双冠"表述。
6. **未报告 V3.7 vs 最优 ML 的配对差 t**：两条高度相关的评分序列，0.1127 vs 0.0961 的 IC 差是否显著从未检验；P1/P3 内部惯例（配对差 t）此处缺席。
7. 术语：config.py:12、engine.py:328、_build_ml_panel.py:2 均写"235**季**×217只"——实为 235 **个月末**（2006-09→2026-03 恰 235 个月）。sloppiness 本身无统计后果，但出现在三处关键"协议声明"位置，说明协议文字未经二次校对。

### F5（P1）同日信号同日成交（T+0@close），未披露

**事实链**：决策日 d = 当月最后交易日；评分 `nav[nav.date <= as_of]` **含 d 日净值**（engine.py:57）；成交价 `px = nav.asof(day)` 同为 d 日净值（四套模拟器一致：`backtest_local`、`p3_backtest`、`strategy_bt`、`strategy_experiment` 的 `previous` 口径也只是映射到 ≤月末的同一交易日，不存在 T+1 选项）。公募开放式基金 T 日净值当晚公布、15:00 前下单才能按 T 日净值成交——**用当日已知净值信号按当日净值成交在执行上不可达**。逐笔含 1 个交易日前视（74–130 笔）；动量/止损/CPPI 类规则均受影响。

**量级判断**：月频低频策略下绝对收益失真有限（单笔约 ±1 日 alpha 噪声），但"当日反转/止损"类叙事（如 V3.7.2 的 924 拐点案例、`conviction`、`p90` 的入场时点比较）会被系统性美化。**通行规范 = 信号 T 日收盘计算、T+1 成交并披露。** 全项目无任何披露。

**修复**：模拟器加 `--exec-delay 1`（信号日次日净值成交）并重跑基线；报告附 T0/T+1 双栏。

### M1（P1）基准为沪深300价格指数

四套回测的基准均为 `idx_sh000300` **收盘价**（价格指数，不含股息再投资）。12 年窗口径下沪深300股息约 1.8–2.5%/年 ⇒ 一切"超额收益 = 策略 tot − 基准 tot"**高估约 2pp/年**。粗算：新面板 v38_cost CAGR 6.16% vs 全收益基准约 8%+ ⇒ **真实口径下策略 12 年跑输基准**；策略的价值主张实际只剩"回撤减半的风险调整形状"（报告 P3 波次1 表格其实已经显示：价格指数基准 CAGR 6.26% > v38_cost 4.50%，靠 MaxDD −46.7% vs −21.5% 才在 Calmar 上胜出——这一事实在 README 传播层丢失）。

**修复**：基准改用全收益（H00300/中证全收益）或至少双列展示；README 删除/限定一切"超额"字样。

## 2. 主要结论的有效性逐项裁决

| 结论（出处） | 裁决 | 理由 |
