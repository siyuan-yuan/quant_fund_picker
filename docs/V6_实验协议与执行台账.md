# V6 动态 Alpha 与 FULL-PIT 实验协议及执行台账

## 1. 研究问题

V6 不再优化 V3.7 的权重、窗口或执行参数，而是依次检验：

1. FULL-PIT 基金宇宙是否改变既有结论；
2. 历史动态 RBSA 暴露是否比“当前权重回套历史”更可靠；
3. flow、AUM、费率、换手率、经理和基金公司信息是否提供独立增量；
4. raw return、style return、skill alpha 中哪一类目标具有可交易的 OOS 预测力；
5. 只有简单模型证明增量后，分层模型是否继续改善结果。

生产 V3.7 在全部门槛通过前保持不变。

## 2. 冻结口径

- 裁决宇宙：2006-01 至 2026-03 的 FULL-PIT 全基金池，包括已清盘、合并和转型基金。
- 过渡宇宙：SURV-ADJ 只用于迁移对照，不产生采纳裁决。
- 数据可得性：所有特征必须满足 `known_at <= decision_date`。
- 训练截止：h 月目标必须满足 `train_date <= prediction_date - h months`。
- 执行：复权净值、T+1；QDII T+2 假设；沪深300全收益基准；沿用 V5 阶梯成本。
- 单因子：月度 Spearman `|IC| > 0.05` 且 HAC `t > 2`；fwd1/3/6 lag 为 1/3/5。
- 因子增量：相对 V3 信息集的截面残差 IC，HAC `t > 2`。
- 模型：全期与近3年 Calmar、MaxDD 双改善；相关配对比较经 Holm 校正显著；报告 DSR 相对变化。
- 多重检验：所有成功和失败变体均进入统一 trial registry 与 CSCV-PBO。
- 禁止修改：V3.7 的 0.40/0.35/0.25 权重、动量窗口、买卖线、CPPI 档位及现行执行参数。

## 4. 预登记变体

### 4.1 动态 RBSA

- `static_60d`：当前 60 日 RBSA 权重回套历史，仅作病灶对照。
- `rolling_ridge_60d`：每个历史时点只用当时过去 60 日估计。
- `kalman_rw`：filter-only 随机游走状态空间模型。
- `kalman_rw` 的过程噪声只比较 `q_scale = 1e-5, 1e-4, 1e-3`。
- 选择只使用合成样本和 2006-2013 诊断段；先满足 MAE≤0.08，再最小一步预测误差，平局取较小值。
- 2014-2026 OOS 开始后不得修改所选 q_scale。

### 4.2 信息集

- `V3`：当前 V3 可用信息。
- `DYNAMIC_ALPHA`：动态异常收益派生的六类 alpha 特征。
- `FUND_OPERATING`：flow、AUM change、flow shock、flow volatility、expense ratio、turnover、manager change、manager tenure、family AUM、fund age。
- `ALL_V6`：上述三组并集，不增加未登记列。

### 4.3 目标和模型

- 主 horizon：6 个月；辅助 horizon：1、3、12 个月，仅报告方向稳定性。
- 连续目标：raw return、style return、skill alpha。
- 分类目标：`skill alpha > 0`。
- 排序目标：同月 skill alpha 百分位。
- 模型仅限：`v37`、`elasticnet_reg`、`lgbm_reg`、`lgbm_binary`、`lgbm_rank`。
- 不进行 Bayesian search，不增加 RF、MLP、TFT 或新的 sklearn 模型。
