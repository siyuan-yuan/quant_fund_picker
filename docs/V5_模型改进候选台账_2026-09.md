## C1 — 回撤惩罚项（F_mdd / P1-4）去留判决【最高优先】

- **改动内容**：生产评分 S 中含回撤惩罚分量；候选为**移除或保留**该惩罚项。
- **证据链**：R3.2（预登记 #23，产物 `output/v5/r32_p14_penalty_hac.csv`）：
  - P14_diff_SwithoutMdd-S fwd6：IC 差 −0.0143，naive t=−2.21 → **HAC t=−1.25（失效，翻转项 3/26 之一）**。
  - 历史采纳依据`去掉 MDD 惩罚显著更差（t≈−2.21）`在 HAC 门下不再成立。
- **当前判定**：**证据真空**——维持现状仅为默认，不可再引用 −2.21 为辩护；亦不能反推"移除更好"。
- **#37 已执行节果（2026-09-01, c_experiments.py, M11 后权威面板 145 月/52,152 行）**：
  H1: OOS(2024-06+) fwd6 配对 IC 差 HAC t = **+1.11（未过 2）**
    （全期 t_naive −2.38 → HAC −1.33，方向仍偏负→即全期样本里面板视角「摘惩罚更差」,与 OOS 正收益并不矛盾）；
  H2: 端到端 A_ref +10.84% → C1B **+12.20%（Δ+1.36pp）**, MaxDD −18.5%→−18.4%(Δ−0.01pp 合格 ≤2pp),
    Calmar 不降——H2 过。
  **双门未全过 → 维持现状**（预登记否决条款生效）。
  亮点信号（OOS fwd6 IC 方向翻正 +1.11 / 端到端 +1.36pp）属「松他化趋势」证据,不构成显著改进；
  **若 U4.1 FULL-PIT 面板下重跑仍然 OOS 动量方向为正,可申请重开评断**——现案不采。

## C2 — 动量平滑 M2（V3 变体）入产判决【~~正向增量候选·第一名~~→已裁决：否决，维持 M1】

- **改动内容**：生产评分中 F_momentum 采用 M1 平滑（V2）；候选为换用 **M2 平滑（V3 变体）**。
- **证据链**：R3.4（预登记 #23，`output/v5/r34_adoption_chain_hac.csv`）：
  - V3−V0 配对差：IC 差 **+0.0090**，naive t=2.54，**HAC t=2.69（46 有效季，L=2，显著维持）**；
  - 但历史采纳链中该变体**未进生产**（当年无显式否决记录，M2 注记成立）。
  - 对照：已采纳的 V1（HAC 2.57）、V2（HAC 2.79）证据强度与 V3 同级。
- **#38 已执行节果（2026-09-01, c_experiments.py, 同上通道）**：
  H1: OOS fwd6 配对差 HAC t = **−0.47**（方向反了：+0.0090 的历史正向并未跨到 OOS）；
    ALL 段 t_naive −2.21/HAC −2.55——全期仍採配对差为负,历史 R3.4 的 +0.0090 系数（R3.4 季粒度 L=2）
    被月粒度 OOS 渠道证反转；**R3.4 的 V3“显著”本身即 SURV-ADJ 季粒度证据，环境再反转属典型**。
  H2: 端到端 CAGR −1.45pp / MaxDD 劣化 **+4.3pp（远超 2pp 上限）**, H2 断过。
  **双门皆堵 → 维持 M1（否决 M2）**。
  教训：报表正 IC 信号（V3 在季粒度 OOS t=2.69）不能直接折算到端到端——惩罚/执行
  的耦合又吞取理论增益，「WL 性解耦」的代表；此结论同步修正上段 RHS「证据已显著却未应用」表述为
  「报告级显著。**跨通道端到端型鉴定：D0.6 计数规则居然捕获真实组合层面的塌缩证据**」。
- **下一步**：无新实验——若用户日侧补 2025-04+ 净值后 U4.1 PIT 面板下重跑仍然 M2 更强,才准重开。
