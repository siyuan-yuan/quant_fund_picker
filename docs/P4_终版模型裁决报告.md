  执行层 11 变体 + 3 参考配置，无一项通过采纳门；P4-1 多重检验审计在新旧两面板均零改判
  （Holm/BH 校正后零显著）**。

  基线 0.750）；新面板 CSCV PBO = 0.90（旧 0.243）→ **系统边缘按"弱-中等统计强度 + 相对最优 +
  风险角色"管理，而非"显著为正"**。维持 V3.8 的依据是：全台账相对最优 + 执行层风险角色（CPPI/
  危机禁买/DD 预算）+ P1 层因子证据，三者叠加；未来任何采纳必须同时过（a）IC 门或模型级双门、
  （b）DSR 相对提升、（c）Holm 显著（如涉配对比较）。
- 适用边界：① 基于**幸存者池**（未清盘基金缺失，T0.2 修正前 CAGR 为乐观上界，V3.7.2 已量化
  三情景区间 +9.0%~+10.3% 为另一口径参考）；② 本地可验证窗口 2014-03 起（2006-2013 待 T0.1）；
  ③ V3.8 宣称的 8.45%/−26.07%/0.324（README，幸存者池 2006-09→2026-03 上界）与严格 PIT 全池 +
  现实成本基线 6.16%/−18.89%/0.326（2014-03→2026-03）**口径不同、不可互比**——研究口径以
  v38_cost 6.16% 为唯一基线（已入 README 注释）。

## §1 cap35 机制核查（预登记 #8，纯诊断，无新回测）

**问题**：旧面板 P3-4 判 STRAT_STYLE_CAP=0.35 为"现金拖累"（持仓 4.5-5.2、现金 48-55%、
Calmar 全低于基线）；新面板上 cap35 双窗越双门（Calmar +0.006/+0.062、MaxDD +1.4/+3.3pp）→
机制是否变了？

**证据（新面板全矩阵产物）**：
1. **无现金拖累**：cap35 vs v38_cost 全期 n_pos 5.8 vs 6.2（Δ +0.40 < 1.0）、cash 41.2% vs
   38.0%（Δ +3.2pp < 10pp）→ 旧面板"挤出只换现金"机制在新面板**不存在**。
2. **真实作用方式 = 入场端风格阻断**：两变体各 74 笔交易，仅 51 笔共同；**v38 独买 23 笔中
   16 笔是创业板50**（cap35 在该风格权重超 35% 时拒买），cap35 独买 23 笔更分散
   （创业板50 入场份额 37% vs v38 的 50%）。
3. **trim 极少**：全期仅 1 次（2019-03-29 一笔决策日卖出 5 只**无风格标签**基金，合计
   −1,828 元；RBSA top1_style 缺失使空串聚成"伪风格簇"，数据质量边界案例）。
4. **年度效应**：分散化在轮动年收钱（2016 +5.74 / 2018 +2.20 / 2023 +5.40 / 2025 +1.41），
   在单边领涨风格年付钱（**2020 −12.66**——被阻断的正是当年领涨的创业板50/成长；2024 −2.37、
   2022 −1.70）。净效应：CAGR −0.35pp、MaxDD +1.4pp 更浅、Calmar +0.006。

**预登记判据执行**：cond_A（现金拖累）= False；cond_B（保护性分散；代理指标 trim≥20 在
新面板属**代理误设**——约束主要在入场端 binding，trim 仅 5 笔）= False → **分类 C 混合/未定**。
机制标签的实质读法：cap35 在新面板是"**入场端风格分散器**"——轮动年收保护费、单边牛市年付
机会成本，全期净效应接近中性偏正（回撤浅 1.4pp 换 CAGR 0.35pp）。

**裁决不变**：P4-1 改判标准（DSR>0.97 且 Holm 显著且双窗双改善）前两项不满足
（DSR 0.792、配对 t −0.42 p 0.67）→ **不采纳**。cap35 与本轮全部 ❌ 一样，是"相对最优 +
风险角色"框架下维持基线的又一例证；其 Calmar 优势纯来自回撤变浅，月均收益更低。
**T0.1 复测触发（C 分支，预登记）**：全期数据复跑双门 + 完整证据包裁决；届时直接量化入场端
阻断（被阻断买入笔数/风格分布），并将"空串伪风格簇"改为显式 no-style 桶。

## §4 监控与复审制度（操作化，随每月数据刷新执行）

1. **P4-2 OOS 监控**：S_total（及 eng_mom/eng_alpha）滚动 12 月 IC(fwd6) / 全期均值 < **0.5**
   → 告警（当前状态：**告警中**，0.32，H-P4A 已闭环为"体制轮动 + 监控"，无模型动作）。
2. **F_alpha 监控因子**：连续 6 个决策月全池 IC(fwd6) < −0.05 **且** 双年符号判据转"连续衰减"
   → 触发重审（流程 = 新的预登记 + HP4A-3 式 PIT 检验；**不自动调权**）。
3. **cap35 复测**：T0.1 解锁 → 全期复跑双门 + 完整证据包（§1 触发词）；空串伪风格簇改显式桶。
4. **H-P2E（tuw252 水下时间）**：T0.2 去幸存者偏差后复测，门 = |IC|>0.05 且 t>2（fwd6）+
   对 S_total 增量 IC 显著；通过才谈入库。
5. **P3-2（A/C 份额优化）**：费率表数据（fund_share 接口或手工维护）到位后另立预登记。
6. **未来验收基线**：一切采纳 = IC 门或模型级双门 + DSR 相对提升 + （涉配对时）Holm 显著。
