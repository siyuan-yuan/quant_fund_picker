## Phase 1 总结与登记假设（供 Phase 2 裁决，非结论）

**入库改动：无。** Phase 1 的全部裁决均为"维持现行"或"否决新方案"——
这本身是有效产出：排除了两条看似合理但被数据否决的路径（正交化、IC重加权），
并确认了动量窗口与两类惩罚的价值。

**登记假设（Phase 2 实验队列，全部待实验裁决）：**
- **H-P2A**：价值因子信息是体制条件性的（底部年份强、2015-2020 弱且负）。
  候选实验：(a) 水位条件化价值权重；(b) 用持仓自下而上基本面重建价值因子（P2-1）；
  (c) 仅底部区启用估值的门控变体。
- **H-P2B**：动量 0.6/0.4 线性混合中 r4 的"破位门"语义可能依赖非线性交互
  （r7 单窗更强但主锚换 r7 全部变差）。候选实验：乘法门变体 vs 线性混合。
- **H-P2C**：风险因子（MDD/集中度/小盘）单因子 IC 不显著但特定年份贡献大，
  价值可能集中在尾部年份 → 应在 Phase 3 组合层（Calmar/MaxDD 门）而非 IC 门检验。
- **H-P2D**（数据缺口）：任期/AUM 惩罚的因子层检验、2006-2012 扩展、幸存者偏差闭环
  → 依赖 Phase 0 T0.1/T0.2（Tushare），完成后**重跑本阶段全部实验**对比。
