### 1.1 三套 target 的定义与恒等式

$$Y^{raw}=R^{fund}_{t\to t+h},\quad
  Y^{style}=\beta_{i,t}'R^{index}_{t\to t+h},\quad
  Y^{skill}=Y^{raw}-Y^{style}$$

`test_skill_identity_holds` 锁死 $Y^{raw}\equiv Y^{style}+Y^{skill}$ 逐行成立（atol 1e-12）。
因 β 已归一到单纯形（$\sum\beta=1$，由 T1 保证），$Y^{style}$ 可读作
**"一个与该基金同等风格配置的被动组合"的持有期收益** —— 这使 skill 具备干净的经济含义。

### 1.2 β 冻结口径（防前视的关键决策）

$Y^{style}$ 用的 β 是**决策日 t 的滤波值**，并在持有期 $[t,t+h]$ 内**冻结**。
理由：决策日只能知道决策日的 β。

持有期内 β 会漂移，冻结因此是一个**已知近似**。计划书 §3 T2 要求量化披露，
`style_drift_diagnostic` 即为此而设：它比较冻结 β 与持有期内实现的 β 路径均值的 L1 距离。
**该诊断量含未来信息，仅用于披露失真幅度，禁止入模**（函数文档串已标注）。

替代方案（用持有期内实现 β 的均值）被明确否决 —— 那是直接前视。

### 1.3 缺失与覆盖纪律

- β 缺失 ⇒ style/skill 为 **NaN**，绝不回填（回填等于编造暴露）；`raw` 不受影响。
- 指数覆盖权重 < 50% ⇒ 不出数，与 F_value 的估值盲区同精神（`test_low_index_coverage_yields_nan`）。
- 截面变换全部**逐截面**计算，不使用任何跨期统计量（承 V5 §0.2-5，即 `impute_features` 全样本中位数兜底那类错误不得重现）。

## 2. 核心命题的端到端最小复现

`test_skill_label_separates_sector_beta_from_true_alpha` 把 T1 与 T2 串起来，
在合成数据上复现计划书 §3 T2 的论证：

**场景**：后半段科技赛道大涨。

| 基金 | 设定 | 真实能力 |
|---|---|---|
| A | 80% 压在 tech，无超额 | **无 alpha**（纯赛道 beta） |
| B | 完全不碰 tech，有 +10%/yr 超额 | **有 alpha** |

**结果**（决策日取 idx[900]，h=6M）：

| code | raw6 | style6 | skill6 |
|---|---|---|---|
| A | **0.2808** | 0.2992 | **−0.0184** |
| B | 0.1398 | 0.0705 | **+0.0692** |

> **raw 排序赢家 = A　｜　skill 排序赢家 = B**

现行标签会把 A 选为正样本（它确实涨得多），模型于是学到"哪种风格会涨"；
skill 标签则正确识别出 B 才是真正有选基价值的那只。这就是 T2 要拆开的两种能力。

**注意**：这只是**方法可行性**的合成验证，**不构成任何关于真实基金的结论**。
真实数据上 style 与 skill 谁更可预测、λ 该取多少，必须等 FULL-PIT 面板（T2.2/T2.3）。
