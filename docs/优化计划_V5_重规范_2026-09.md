# 量化选基系统 V5 重规范实验总计划与执行记录（2026-09-01 起）

> **总纲**：
> 1. 本文件是"实验协议 + 执行记录"二合一：**每项研究先登记假设与判定规则，完成后只把客观结果写回状态表**。
>    标记约定：✅(按预登记完成) / ❌(完成且按门否决) / 🔶(受阻/噪声，处置已写明) / ⬜(未开始) / 🔄(进行中)。
>    **状态表只追加客观结果数字，不修改任何已写下的判定规则。**
> 2. **不预设任何改动是好的，也不预设任何改动是坏的。** 维持现状与推翻现状同为合法结论；显著为负同样入库。
>    每一行结论必须对应可复现命令与产物路径；口径不达标的数字只可作"修复前后差异"的对照事实，不得作裁决证据。
> 3. 目标数据口径（本计划的存在理由）：**2006-01 → 2026-03、全基金池（含已清盘/合并/转型基金）、严格 Point-in-Time**；
>    执行口径：成交价复权、T+1 成交、全收益基准、统一成本阶梯。
> 4. 预登记纪律：每项实验的假设/步骤/判定门在本文件 §3 登记后**先单独 commit**，运行结果后随 commit（修复审查 M8：时序可外验）。
> 5. 任何新机制/新变体，不经本计划新登记（预登记下一号 **#10** 起）不得进入裁决。
> 6. 幸存池口径完成的工作（Phase 2/3）一律带 **SURV-ADJ** 标签：仅用于口径修复对账与差异量化；
>    最终采纳/否决裁决一律以 Phase 4/5 的 **FULL-PIT**（全基金池）口径为唯一有效证据。
> 7. 本计划起因：`docs/审计报告_实验严谨性审查_2026-09-01.md` 的 F1–F5、M1–M10；每项实验的"修复对象"列明对应编号。

### 0.2 严格 PIT 规则（违反任一 = 产物作废）

1. 决策日 d 只允许使用 d 日收盘前实际可得数据：净值截断至 d（含 d）、PE 截断至 d、指数/宏观至 d；
   经理任期/AUM/基金类型**只允许来自历史快照**，快照缺失则该因子禁用并打标（延续引擎 bt 语义）。
2. **宇宙成员资格必须 d 时点可知**：类型/名称/份额归并只能来自 ≤d 的名录快照；早于快照起点时用
   最近一次早于 d 的快照 + 成立日推定，推断所占比例逐月披露（D0.5/D0.6 量化不确定性的预登记规则）。
3. **禁止一切后向资格过滤**：不得用"月末净值是否存在""之后 N 日是否仍有披露""是否存续至今"等未来信息
   决定 d 时点样本资格（修复对象：`_build_ml_panel.py` 的 `nav_last ≥ date+60d`、`backtest.build_pool` 的
   末净值条件、`p1_panel_build.uni.last` 衍生条件的每一次使用都需重新审读是否符合本条）。
4. 前瞻标签 fwd1/3/6/12 仅用于评估；训练样本只允许使用**在决策日已完整成熟**的标签
   （h 个月目标 ⇒ 训练截止 ≤ q−hM；修复 `_model_zoo.py:125` 对 fwd12 硬编码 6M 的错误）。
5. 缺失值填充只允许逐日截面或扩展窗历史统计量；**禁止全样本统计量**（修复 `impute_features` 的 `gmed` 全期中位数兜底）。
6. 截面参照系（动量 ECDF-rank 等）逐日构建、批间一致；批内 rank vs 全市场 ECDF 的差异入 S6.1。

### 0.3 统计裁决门（全阶段统一；替代 V4 §0.3 口径）
