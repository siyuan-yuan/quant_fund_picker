## 一、真正改变了生产数字的改动（诚实口径：评分逻辑=零；基线数字被口径修复改写）

先说结论再给证据。**在本研究轮内没有任何一个"模型改进"通过门并入库**，所以本节的严格回答是：

> 若"生产数字"指**评分/执行逻辑对选基的排序贡献** → **改动 = 0**（35+11+3 全 ❌/维持）。
> 若"生产数字"指**对外报告的那串 CAGR/MaxDD/Calmar 基线** → 有一处被**口径修复**改写（C5），
> 那是测量校正而非模型提升，且方向是"把真实的它找回来"而非"让模型更强"。

### 1.1 评分逻辑改动：零（35+11+3 全部未过门）

判定门：§0.3（V5 主契约）变体/权重门 = 对基线**配对差序列 HAC t>2 且全期+近3年双窗同向**；
模型级 = 端到端 **Calmar 与 MaxDD 双改善**且双窗成立 + Holm 显著 + DSR 相对提升。
结果（产物路径 → 口径 → 窗 → 门 → 裁决）见 §二 否决清单。无一反向通过 ⇒ 零入库。

### 1.2 真正提升了排序质量的实体：本轮**之前**的采纳链（V3.4→V3.7），本轮复核仍存活

这是全仓库唯一能指向"评分逻辑相对其 V0 基线确有增量"的一条链：

| 项 | 值 | 口径/窗 | 门 |
|---|---|---|---|
| S_eng（现行 V3.7 分）− V0（未平滑基线）IC 差 | **+0.0209** | SURV-ADJ · 46 有效季（R3.4）| HAC t=**3.32** >2 ✅，0 翻转 |
| 平滑采纳链各步对 V0 的配对差 | 各步 HAC t 见右 | 同上（季粒度 fwd6）| V1−V0 2.57、V2−V0 2.79、V3−V0 2.69（均显著）；S4−V0 −1.08（否决维持）|

产物：`output/v5/r34_adoption_chain_hac.csv`（勘误表见 勘误追加段_HAC复核 / R3.4 行）。
**为何允许落地**：它在本轮开跑前就已落进 V3.7（2026-08-10 起为唯一模型），本轮 R3.4 只是把当年的
t=3.42/3.46 **替换引用为 HAC 口径并验证不翻转**——即它经得起本轮最严复核，是本轮能"背书"而非"授予"的改进。

### 1.3 执行口径修复（C5）：改的是"数字"，不是"模型" —— 但仍列为改变生产数字的真实项

分解（产物 `output/v5/b21_decomposition.csv`，M11 修复后基准；口径 SURV-ADJ · 窗 2014-03→2026-03 · V3.8 默认执行层）：

| 档 | CAGR | 增量 | 性质 |
|---|---:|---:|---|
| R0（raw nav，历史口径）| +5.08% | — | 被 F1 证伪：分红被记作亏损 |
| R1（+复权成交/盯市）| +8.59% | **+3.51pp** | 修正 F1（复权把红利算回收益）|
| R2（+T+1 成交）| +10.73% | +2.14pp | 修正 F5（执行延迟）|
| R3（+阶梯成本）| **+10.84%** | +0.11pp | 修正 M6（成本真实化）→ **基线封死** |

结论：复权修复把 CAGR **抬高**了 3.51pp（因为旧的 raw-nav 在系统性**低估**——分红除息被当亏损，
审计实证平均低估 0.59%/年、个案 12.6%/年）。所以这不是"我把模型做大了"，而是"模型本来就没那么差，口径错了"。
**R3 = +10.84% / −18.5% / Calmar 0.59 现为 SURV-ADJ 唯一权威基线**（C5 封口，禁再改口径）；
对比：审计前 README 的 8.45% 与 P4 轮的 v38_cost 6.16%（raw + 旧面板）均为历史档案，不可互比。

**归零提醒**：即便 1.2/1.3 都成立，它们都不是"本轮实验让我赢了更多"；若问"本轮有没有哪条实验结论升级了排序效果"——**没有，零**。

## 三、证据真空：维持现状但原依据已失效（这是本项目最诚实的一节）

本仓库自己把这类列为最高价值发现——"证据失效 ≠ 证明有害，只证明原依据不能再辩护"。V5 版二向裁决铁律即为此。

### 3.1 【最高优先】MDD 乘法惩罚（P1-4 消融结论失效）
- **原来凭什么**：P1-4 消融"去掉 MDD 惩罚" IC 显著变差（diff naive t=−2.16）→ 惩罚有正贡献，保留。
- **现在为何不能再凭**：HAC 复核（R3.2 / `r32_*.csv`）t→**−1.25 不显著** ⇒ 该惩罚的 **fwd6 IC 增量主张无证据**。
- **重开评断条件**：已跑 C1 双门（§二.3）——H2 端到端 ΔCAGR **+1.36pp** 而 ΔMaxDD **−0.01pp** ⇒ 在 SURV-ADJ 幸存池里
  该惩罚"没兑现风控价值却在吃收益"，但 H1 未过故不采。**幸存者偏差恰会系统性低估回撤**（清盘/巨亏基金被剔出池），
  故 **FULL-PIT 全池口径下**该惩罚的风控价值可能被重新证实、也可能被彻底否定——这是全项目**信息量最高的一次复核**，
  C1 已登记为 FULL-PIT 打通后第一批。

### 3.2 alpha_ir 因子权重/独立预测力（R3.1 失效）
- 原来：alpha_ir fwd6 naive t=2.41 → 引用为独立 alpha 证据。HAC 复核 **1.30 失效**（ashare 1.52 同失效；海外 alpha_dc 1.25）。
- 现在：**依据弱化，不构成"移除"证据**，也不构成"保留 alpha 权重"的辩护。fwd1/fwd3 未翻转，失效集中在 fwd6 独立预测力这一引用面。
- 重开条件：A5.1（FULL-PIT 因子体检）全 horizon 终审；此前凡引用 alpha_ir 独立 alpha 处按勘误降级措辞。

### 3.3 mom4 fwd3（naive 2.56→HAC 1.91）、value fwd3 / eng_value fwd3（均翻转）
这几个是 P1 里"边缘显著的因子门槛"表述，HAC 后撤回显著性（方向性描述保留）。不推翻 V3.7（合成 IC 靠 mom/alpha 双支柱，
mom7 与 eng_mom HAC 后仍显著）。但**一切"单因子 t>2 即门槛成立"的历史措辞自 2026-09 起作废**（§五 HAC 全局）。

### 3.4 P4-2 OOS 告警：原"有 edge 的合理性"现在是警报态
- 原来：S_total 全期 IC 0.131 显著 → 系统有 edge。
- 现在：**S_total 滚动 12 月 IC 0.042 = 全期 32% < 0.5 预登记告警线 → ⚠️ 告警中**（近24月 IC≈0.006）。
  分解：F_momentum 偏强（2025 +0.168），F_alpha 全群翻负（2025 −0.099），F_value 恶化（−0.160）。
  且 F_alpha 双年负（2024 −0.043 / 2025 −0.107）触发"连续衰减"标签。
- 现在不能再凭："全期显著 → 会持续"；当前正确读法是**体制轮动 + 监控**（H-P4A 已闭环为不退役、不动权）。
- 重开评断条件：**不可对 2025 窗口事后调权**（纪律）；只能走新预登记。P4-2 滚动监控 + S6.3 前瞻纸面 12 个月观察期。

## 五、方法论层面的真实收获（本项目最有价值的部分）

### 5.1 HAC 复核翻黑了多少？naive/HAC 系统性虚高实测幅度？
- **显著性翻黑（显著→不显著）计数，按层：**
  - R3.1 因子体检：全样本 **4/39** + 子群 **6/35** 翻转（value fwd3、alpha_ir fwd6、mom4 fwd3、eng_value fwd3 + 子群 alpha_ir/mom4/alpha_dc 等）。
  - R3.2 正交化/惩罚：**3/26** 翻转（S1 正交 fwd3/fwd6 证据失效；P1-4 MDD 依据 −2.21→−1.25 失效）。**S2 fwd6 −2.45 存活**。
  - R3.3 P2 低波/体制：**1/41** 翻转（ntuw252 fwd1 2.04→1.92）；ntuw252 fwd6 **2.33 存活**、fwd3 2.87 存活。
  - R3.4 V3.6/3.7 采纳链：**0 翻转**（生产采纳链在 HAC 严口径下未出现"由显著变不显著"的采纳级翻黑）。
  - m12b 余项：HP4A-3 OOS 中间门 naive 2.50→**HAC 1.61 翻转**；S3r 2.06 擦线存活；终局裁决（HP4A-4 双门）独立不受影响。
  - **汇总**：约 14 项测试级显著性翻黑 + HP4A-3 中间门翻转；**采纳级翻黑 = 0**（V3.4→V3.7 链 + 各否决裁决全部顶住）。
- **naive/HAC 系统性虚高实测**：`|t_naive|/|t_HAC|` 在 fwd6 月度序列**中位数 ≈ 1.7×**（P1/P2 勘误元结论），
  与 6 期重叠的理论上界 √6≈2.45（全窗 √11≈3.3）一致、落在其中；P2 生存余量 4.13→2.33 ≈ **1.8×**。
  即：**历史上所有"t≈3~4"的报告值，真实统计意义大约要打 1.7~1.8 折。**（参考：zoo V3.7 的 naive 8.11→HAC ~3.3，仍显著。）

### 5.2 F4（标签窗前视）爆炸半径实测
- **实测**（R3.5 / `output/v5/r35_zoo_redo/fwd12_ab.csv`）：把 huber F2 fwd12_z 的训练截止由硬编码 q−6M 改为 h 匹配的 q−12M，
  IC **+0.0773（naive 4.20）→ −0.0842（HAC −2.00），符号翻转**；V3.7 与该配置配对差 HAC **3.36** 显著。
- 结论：**一处标签窗前视足以把"看似全场最佳"的配置翻成显著为负。** 爆炸半径限于单一配置（huber fwd12_z），
  主结论方向不受影响——审计 F4 判断被实测证实。已落地 C8 硬断言（`research_guard.py`）+ #16 十用例防复发。

### 5.3 M11（并发行序非确定）这类工程缺陷对结论稳定性的实际影响
- **性质**：`ThreadPoolExecutor+as_completed` 下按线程完成顺序收行 → 面板**行序**不确定 → 并列分（S 相同）在
  slots=10 满槽时"谁进谁不进"逐轮漂移。**任何基金的得分一分没变**，变的是并列个案的槽位裁决。
- **影响实测**：端到端 B2.x 交易笔数漂移（76↔81 笔）、CAGR ±0.6pp、MaxDD/换手同量级；
  **一切 IC 类统计（R3.x 翻转判定）三轮逐位一致 → 对漂移免疫**。这也解释了为什么"看似同样代码重跑数字不同"。
- **处置**：M11 修复（按 code 稳定排序 + mergesort 稳定序）后基准面板**唯一冻结**；此前各轮 B2.x 数字只作"漂移区间见证"，
  不再作裁决输入。M13（workers 硬编码）同族，修复后验证线程数无关性（sha256 逐位一致）。
- **对结论的意义**：不改变任何方向性结论，但证明**工程确定性是可复现性的前提**；端到端数字必须在确定性冻结面板上才可信。

### 5.4 双门制（IC 层 + 端到端层）拦下了哪些"看起来能用"的改动
这是本项目方法论最硬的一件东西——**IC/OOS 看着漂亮 ≠ 端到端能赢**。实证案例：
| "看起来能用" | 为什么被拦下 |
|---|---|
| H-P4A S3 PIT 重加权（spit）| OOS 2024-25 IC 大优、近3年 CAGR +7.97 vs −2.92，**但全期 CAGR 5.59<6.16、换手 123 vs 74、成本 7,575 vs 3,979、DSR 0.557** → 双门不通过 |
| C1 去掉 MDD 惩罚 | 端到端 CAGR +1.36pp 漂亮，但 IC 层 OOS 配对 HAC t=+1.11 未过 2 → 双门未全过 |
| C2 动量平滑 M2 | 报表级季粒度 OOS t_HAC 2.69 显著，但月粒度 OOS t=−0.47 + 端到端 MaxDD 劣化 +4.3pp → 双门皆堵 |
| ML 腿（R3.5）| IC 层区分不出（样本不足），端到端 36/36 劣化 → 明确不占优 |
| cap35 | 双窗 Calmar 双改善，但配对 t=−0.42 + DSR 0.79 → 不满足 DSR/Holm/改判标准 |

**底层机制**：IC 空间的窗口性/报表级优势，经过执行层（成本、换手、路径依赖的 CPPI/止损）后常被吞掉甚至反转。
"个案赢 ≠ 组合赢"是 H-P4A 与 C2 共同刻下的教训。

## 六、当前模型相对起点，究竟处在什么位置

诚实回答，分三层，不混：

1. **相对本轮研究（2026-08-31 起）的起点：评分与执行逻辑零改变。** V3.7 评分（0.40·F_value+0.35·F_alpha+0.25·F_momentum + 平滑惩罚链）
   与 V3.8 执行层（10 槽/70/45/现金 2.5%/季再平衡/20% 移动止损/危机禁买/CPPI 15/20/25）**在本轮一字节未动**。
   终判报告原文：**"V3.8 维持为最终研究版，模型零改动。"** 本轮 100+ 个实验的全部净效应是**确认维持**，不是改造。

2. **相对更早的模型演化起点（V3.1 之前/ V0 未平滑基线）**：本仓库版本史 V3.1→V3.8 确实改变了评分逻辑——
   V3.4/3.5（R_MDD 悬崖→缓坡、任期归零→折价阶梯）→ V3.6（惩罚平滑化）→ V3.7（因子平滑、删 V4 ML 腿）→ V3.8（执行层）。
   其中"平滑化采纳链"经 R3.4 复核是**真提升**（V3.7−V0 IC +0.0209，HAC 3.32）。所以严格说：
   **从项目最初到现在，评分逻辑变了很多（这些是本轮之前被采纳的）；但从"本轮研究开始前那刻"到现在，一点没变。**

3. **相对"绝对真理"（FULL-PIT 全基金池）的位置**：**未知且未达**。当前一切结论都在 SURV-ADJ（幸存池）口径上；
   幸存者偏差未修正（缓存 0 死亡基金）、2006–2013 窗口不可验证、绝对收益数字（README 8.45%、严格 PIT 基线 6.16%、
   重述后 R3 10.84%）**口径各不相同，均不可作为"真实可期望收益"**（审计 F1/F3/F5/M1 四重失真）。FULL-PIT（D0.1/D0.3/D0.5）
   仍被外部数据阻塞。**唯一能站住的位置断言是**：在本仓库能被验证的窗与池内，V3.7/V3.8 是"经得起 HAC 复核的、未被任何候选中途推翻的相对最优"，其统计强度被明确标为**弱-中等**（DSR 无 ≥0.97、新面板 PBO 0.90）。

> 一句话：**V3.7 不是"被这轮实验证明的最优"，而是"这轮实验没能证伪的现状 + 之前采纳链确实有效"。**
> 这是强度上差别巨大、但完全诚实的表述。
