## 1. 环境与前置

```bash
git clone <repo> && cd quant_fund_picker
git checkout arena/01a05f52-quant-fund-picker
python3 -m venv .venv_review
./.venv_review/bin/pip install -r requirements-v5-lock.txt requests py_mini_racer
```

**数据前置（必须有）**：`cache/nav_*.csv` 15,444 只 + `cache/idx_sh000300.csv` + `cache/fund_meta.csv`。
若本机尚未缓存，先跑 `python t0_fetch.py`（需网络；沙箱内三源不可达）。
`cache/` 与 `output/` 均被 `.gitignore` 排除，**产物不入库**（纪律 §0.4）。

## 2. 一键入口

```bash
chmod +x run_local_batch.sh
PY=./.venv_review/bin/python ./run_local_batch.sh s61 6     # S6.1：11 组面板，6 路并行
PY=./.venv_review/bin/python ./run_local_batch.sh r35 8     # R3.5：缓存 8 路 + ML 面板 + zoo 重跑
PY=./.venv_review/bin/python ./run_local_batch.sh all 6     # 先 R3.5 后 S6.1
./run_local_batch.sh status                                 # 只看进度（随时可中断、可续跑）
```

直接调用脚本亦可：
```bash
python s61_runner.py --parallel 6 --workers 2            # 新增 --parallel / --only（组级并行，网格不变）
python r35_rebuild_zoo_cache.py --workers 8              # 新增 --workers N（月级并行）
```

## 5. 纪律（本机执行同样受约束）

1. **口径标签**：本批产物一律 **SURV-ADJ**。任何绝对收益/IC/胜率数字对外引用必须带标，
   **不得**冒充 FULL-PIT（U4/A5 未解锁）。
2. **不作采纳裁决**：S6.1 是"仅报告、不平判"（#33 自封）；即便组间离散度大到足以动摇既有结论，
   也只登记为**稳健性告警**，不得据此改门或改模型。
3. **R3.5 不预设方向**：V3.7 维持 / ML 反超 / 两者无统计区分，三者同为合法结论；
   结论一律以**配对差 HAC t** 表述（§0.3），禁止用两条 IC 各自 t 值大小比较。
4. **禁再调参**：S6.1/S6.2 的网格与邻域结果严禁反哺参数选择；那是过拟合陷阱。
5. **先登记后跑**：任何新机制/新变体须先在 `优化计划_V5_重规范_2026-09.md` 登记（预登记下一号 #39 起），
   冻结判定门后再执行；跑完只看数字，**禁事后改门**。
