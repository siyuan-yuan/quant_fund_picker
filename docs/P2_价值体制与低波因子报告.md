## 1. P2-A 价值因子体制条件化（H-P2A）

### 1.1 背景
P1-1 发现 eng_value 全周期 fwd6 IC = −0.034（t=−1.28，不显著），但年度 IC 呈体制依赖：
2014 +0.461、2021 +0.366 强正，2015–2020 持续为负（−0.16~−0.30）。
H-P2A：价值腿的价值集中在"低水位（底部区）"，高水位月份门控/降权价值腿可提升合成 IC。

### 1.2 方法（预登记 #2，未新增超参数）
在面板上逐月重建四个合成（权重随水位、penalty 链与 V0 完全相同，engine 同式归一合成）：
- **V0 现行**：water≤0.20 → 0.55/0.35/0.10，否则 0.40/0.35/0.25（v/a/m）。
- **V1 门控**：water>0.35 的月份价值腿置零，a:m 按 0.35:0.25 归一（0.583/0.417）；其余月份同 V0。
- **V2 三档**：w_v = 0.55/0.35/0.20（water ≤0.20 / ≤0.35 / >0.35），a:m 恒 0.35:0.25。
- **V3 对照**：全程无价值腿，a:m = 0.35:0.25。
判定门：V1/V2/V3 对 V0 的月度配对差 t，**全期 + 2023-04+ 双窗 |t|>2 且同向**才谈采纳。

### 1.3 结果
**校验**：S_V0 与面板 S_total 最大差 0.05（纯舍入，与 P1-2 同口径）→ 重建可信。

### 1.4 裁决：**❌ 否决，维持 V0（现行 0.40/0.35/0.25 + 左侧 0.55/0.35/0.10）**
1. **V1（门控）无任何效应**（全期 t=−0.005，仅高水位子样本 t=−0.005）：
   说明高水位月份价值腿对合成 IC 的边际贡献本来就≈0——门控它既无成本也无收益，
   不构成加复杂度的理由。
2. **V2（三档）方向为负**（全期 t=−1.96 贴近但未过门、近3年 −1.26）：
   低水位月把价值权重提到 0.55 反而降低 IC（0.1455→0.1325）。
   P1-1 看到的"底部年份价值 IC 强正"（2014/2021）是**因子 IC 年度层面**现象，
   与"月末水位分档"在时间轴上并不重合（2014 为 V 型反转，月度水位信号滞后/错位），
   用月末水位做价值腿开关捕捉不到该效应，反而稀释。
3. **V3（全去价值）为负**（−1.40 / −1.58）：价值腿整体不是有害的，
   而是"低水位有正贡献、高水位中性"——与 V1 零效应互证。
4. 结论链闭合：**H-P2A 以"水位体制条件化"形式被数据否决**。
   价值因子若未来复活，需要的是新信息源（P2-1 基本面重建）而非再分配现有权重。

## 2. P2-2 低波因子族（F_vol）

### 2.1 方法与口径
辅助面板（严格 PIT，只用决策日及以前净值）：
- vol126 / vol252：过去 126/252 个交易日日收益率 std × √252；
- tuw252：过去 252 天中净值低于该 252 天窗口最高值的天数占比。
因子一律**负值化**（低波=高分）：nv126 / nv252 / ntuw252。
特质波动（需基准构造）按预登记排除。
判定门：|IC(fwd6)|>0.05 且 t>2 才入库；辅助：fwd1/fwd3、五分位价差、对 S_total 增量 IC（秩空间 OLS 残差）。

### 2.2 结果（n=133 月，fwd6 为主）

|---|---|---|---|---|---|---|---|
| −vol126 | −0.0122 (−0.36) | +0.0117 (0.35) | +0.0125 | 0.38 | **−2.69%** | 0.0014 (0.05) | 否 |
| −vol252 | −0.0154 (−0.47) | +0.0059 (0.18) | +0.0100 | 0.31 | **−2.73%** | −0.0035 (−0.12) | 否 |
| −tuw252 | +0.0328 (2.27) | +0.0520 (3.72) | +0.0496 | **3.97** | +1.13% | −0.0013 (−0.12) | **否**（0.0496<0.05） |

|---|---|---|---|---|---|

ntuw252 年度 IC（fwd6，诊断性，不参与裁决）：
2016 +0.100 / 2017 +0.144 / 2022 +0.145 / 2023 +0.114 强；2015 −0.053 / 2024 −0.043 负；
其余年份 +0.015~+0.061。→ 同样是"平稳上行年有效、深跌年失效"的体制型因子。

### 2.3 裁决：**🔶 低波族本期不入库（无一过门）**
1. **−vol126 / −vol252 否决**：IC≈0 且五分位价差为**负**（−2.7%/6m）——
   在本池（偏股/指数股主动+被动混合）里，"过去 6-12 个月低波"的基金是**滞涨/沉没风格**基金，
   低波标签与动量负相关，直接按低波选股会输给组合内的高动量部分。与 A 股个股"低波溢价"
   文献结论相反，如实记录。
2. **−tuw252（水下时间）：统计显著但未达 IC 门，且增量为零**：
   t=3.97（fwd6）说明信号真实存在（且跨 fwd1/3/6 单调增强、子群稳定：passive 0.092、
   overseas 0.089），但 IC=0.0496 差 0.0004 未过 |IC|>0.05 门；
   更关键的是**对 S_total 的增量 IC = −0.0013（t=−0.12）≈ 0**——
   现有合成（含 MDD 惩罚与趋势门）已完全覆盖该信息，加入只会重复计分。
   按预登记门：不入库。
3. **登记 H-P2E**：tuw252 是本期唯一"真实但冗余"的因子。
   触发复测的条件（任一）：(a) T0.2 去幸存者偏差后面板重跑，IC/增量 IC 变化超噪声；
   (b) 未来做**组合层风险叠加**（执行层）而非打分因子时，单独评估其尾部保护价值
   （H-P2C 的延伸）。在此之前不再触碰。

## 3. 阶段结论（本地波次）

1. **模型无任何改动**：V0 权重、penalty 链、动量窗口、因子构成全部维持 P1 裁决状态。
2. 两项实验共同指向同一事实：**当前 S_total 在该池（2013-2026，幸存者口径）上
   已接近局部前沿**——可再分配的权重（P2-A）无可图，新信息源（P2-2 低波族）或不存在
   （vol 族）或已被覆盖（tuw252）。
3. 下一步杠杆全部在**数据层**：T0.1/T0.2（Tushare 解锁 → 2006-2012 扩展 + 去幸存者偏差）
   是 P2-1（基本面）、P2-3（经理）、P2-4（份额流）以及 H-P2E 复测的前置条件。
   本地数据已无可再榨取的一阶改进。

## 4. 已知局限（如实披露）
- 幸存者偏差未除（缓存仅现存基金）→ 全部 IC 为上界口径；tuw252 在去偏后可能更强也可能消失，
  故未敢入库。
- 类型用今日名录（无历史快照）→ 被动/主动子群划分存在轻微时点错配。
- 水位分档（P2-A）为月末单点值；2014/2021 类 V 型反转中月末水位信号滞后——
  这是 V2 失败的直接解释之一，但不改变"预登记门未过"的裁决。
- 133 个月的 fwd6 样本尾部约 1.5 年缺失（按 horizon 各自 dropna）。
